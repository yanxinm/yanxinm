# IPTV 直播电视设置

## 什么是 IPTV

IPTV = 通过网络看直播电视，不需要有线电视/机顶盒。只需要：
1. **直播源地址**（M3U/TXT格式）
2. **播放器APP**

## 平台配置指南

### 小米电视

**关键信息**：小米电视自带的"看电视"功能**不支持**自定义直播源地址，必须安装第三方APP。

#### 方法一：应用商店安装（最简单）

| 步骤 | 操作 |
|------|------|
| 1 | 打开小米电视"应用商店" |
| 2 | 搜索"电视家"或"HDP直播" |
| 3 | 直接安装 |
| 4 | 打开即可看直播（自带直播源） |

#### 方法二：U盘安装第三方APP

| 步骤 | 操作 |
|------|------|
| 1 | 电脑下载APK |
| 2 | U盘拷贝APK文件 |
| 3 | 小米电视：设置 → 账号安全 → 允许安装未知来源应用 |
| 4 | U盘插电视，打开"高清播放器"或"文件管理" |
| 5 | 找到APK，安装 |
| 6 | 打开APP，添加播放列表地址 |

## 常见问题

### Q: 小米电视自带"看电视"能添加自定义直播源吗？
A: 不能。必须安装第三方APP。

### Q: 直播源加载失败怎么办？
A: 检查网络连接，或换备用直播源地址。直播源可能随时失效。

### Q: 哪个APP最好用？
A: 追求体验选 TiviMate，追求省事选电视家。

### Q: 需要基地参与吗？
A: 不需要。直播源是在线的，电视直接访问即可。
