> 地域：中国大陆中文圈
> 目标用户：从业者
> 调研日期：2026-05-16

## 一、Newsletter / 公众号（前8个）

### 1. 传媒茶话会
- **类型**：微信公众号
- **运营方**：中国新闻出版传媒集团
- **简介**：传媒行业头部公众号，每日推送传媒政策解读、媒体融合案例、行业趋势分析。城市文旅传播类内容常以案例分析形式出现。
- **来源URL**：公众号搜索「传媒茶话会」；官网 http://www.chinaxwcb.com
- **可信度**：⭐⭐⭐⭐⭐（官方媒体背景，权威性高）
- **更新频率**：工作日每日更新，日更1-3条

### 2. 新闻与写作
- **类型**：微信公众号 / 学术期刊
- **运营方**：北京日报报业集团
- **简介**：新闻传播学核心期刊的公众号，关注新闻业务创新、融媒体案例，城市报道、文旅传播选题常见。
- **来源URL**：公众号搜索「新闻与写作」；杂志官网 http://xwyxz.bjd.com.cn
- **可信度**：⭐⭐⭐⭐⭐（北大核心期刊）
- **更新频率**：日更，工作日为主

### 3. 中国记者
- **类型**：微信公众号 / 学术期刊
- **运营方**：新华通讯社
- **简介**：新华社主管的新闻专业期刊，关注媒体深度转型、重大报道策划、国际传播能力建设。城市品牌传播选题频出。
- **来源URL**：公众号搜索「中国记者」；官网 http://www.cnr.cn/zgxz
- **可信度**：⭐⭐⭐⭐⭐（新华社背景，部级期刊）
- **更新频率**：每周3-5篇

### 4. 德外5号
- **类型**：微信公众号
- **运营方**：央视市场研究（CTR）
- **简介**：专注媒体融合转型与传播效果评估的垂直公众号。常发布城市媒体传播力排行榜、融媒体中心运营报告。
- **来源URL**：公众号搜索「德外5号」
- **可信度**：⭐⭐⭐⭐（CTR专业研究机构背景）
- **更新频率**：每周1-2篇深度分析

### 5. 广电独家
- **类型**：微信公众号
- **运营方**：「广电独家」编辑部
- **简介**：聚焦广播电视媒体转型与新媒体运营，覆盖城市台改革、政务新媒体、融媒案例。城市文旅传播案例丰富。
- **来源URL**：公众号搜索「广电独家」
- **可信度**：⭐⭐⭐⭐（广电行业资深媒体）
- **更新频率**：工作日日更

### 6. 城市进化论
- **类型**：微信公众号
- **运营方**：每日经济新闻
- **简介**：专注城市发展与区域经济的公众号，常发布城市品牌营销、文旅消费、城市传播策略类深度文章。对城市宣传从业者参考价值高。
- **来源URL**：公众号搜索「城市进化论」
- **可信度**：⭐⭐⭐⭐（正规财经媒体）
- **更新频率**：日更

### 7. 传媒内参
- **类型**：微信公众号
- **运营方**：传媒内参（北京）传媒科技有限公司
- **简介**：传媒行业深度观察媒体，覆盖媒体融合、广电新媒体、MCN机构、城市传播等话题，设有「城市融媒」专栏。
- **来源URL**：公众号搜索「传媒内参」
- **可信度**：⭐⭐⭐⭐（行业第三方观察）
- **更新频率**：日更

### 8. 全中看传媒（原「清华传媒评论」部分延续）
- **类型**：微信公众号
- **运营方**：原清华大学新闻与传播学院团队/现独立运营
- **简介**：侧重传媒政策解读、媒体融合路径研究、城市媒体发展报告转发。学术与行业结合较好。
- **来源URL**：公众号搜索「全中看传媒」
- **可信度**：⭐⭐⭐⭐（学术背景）
- **更新频率**：每周2-3篇

## 三、行业会议 / 论坛（前5个）

### 1. 中国新媒体大会
- **主办方**：中华全国新闻工作者协会（中国记协）、中央网信办、湖南省委宣传部等
- **简介**：国内新媒体领域最高级别会议之一，每年在长沙举办。涵盖内容创新、技术赋能、媒体融合等分论坛。2024年大会设有内容创新论坛和省级融媒案例分享。
- **时间**：每年7-10月（2024年：10月；2025年：预计下半年）
- **地点**：长沙
- **来源URL**：http://www.zgxmt大会.com （搜索"中国新媒体大会 2024"）
- **可信度**：⭐⭐⭐⭐⭐（国家级会议）
- **受众**：全国主流媒体新媒体负责人、融媒体中心主任、城市宣传部门

### 2. 中国网络媒体论坛
- **主办方**：中央网信办、中华全国新闻工作者协会、地方政府
- **简介**：中国网络媒体领域最高规格论坛，聚焦网络内容建设、媒体深度融合发展。城市传播、政务新媒体是常设议题。
- **时间**：每年1次（近年多在4月或10月）
- **地点**：轮流（2023年在南京，2024年在广州）
- **来源URL**：http://www.cac.gov.cn （中央网信办官网发布通知）
- **可信度**：⭐⭐⭐⭐⭐（国家级论坛）
- **受众**：网信办系统、主流媒体、城市宣传部门

### 3. 融媒体与城市传播论坛
- **主办方**：各高校新闻学院（如复旦大学、中国传媒大学、同济大学等）与地方宣传部门联合主办
- **简介**：学术与业界结合的论坛，讨论融媒体中心的城市传播实践、城市品牌塑造、文旅整合传播。
- **时间**：不定期（近2年每年至少1-2场）
- **地点**：轮流（上海、北京、成都等地）
- **来源URL**：搜索「融媒体 城市传播 论坛」；例：https://am.tongji.edu.cn/info/1448/3271.htm （同济大学城市传播论坛）
- **可信度**：⭐⭐⭐⭐（学界+业界联合）
- **受众**：融媒体中心从业者、高校传播学者、城市宣传干部

### 4. 中国国际文化旅游博览会（及配套论坛）
- **主办方**：文化和旅游部、山东省政府等（轮值）
- **简介**：文旅产业国家级博览会，设有文旅新媒体传播论坛、城市文旅品牌营销分论坛，展商包括各地文旅局、媒体MCN、传播机构。
- **时间**：每年9-11月
- **地点**：济南（常设）/ 其他城市轮值
- **来源URL**：https://www.mct.gov.cn （文化和旅游部官网发布通知）
- **可信度**：⭐⭐⭐⭐（国家级博览会）
- **受众**：文旅局新媒体运营、城市宣传部门、文旅品牌方

### 5. 世界互联网大会·媒体融合论坛
- **主办方**：国家互联网信息办公室、浙江省政府
- **简介**：世界互联网大会乌镇峰会的分论坛之一，聚焦媒体融合、智能传播、城市形象国际传播等议题。
- **时间**：每年11月
- **地点**：浙江乌镇
- **来源URL**：https://www.wicwuzhen.cn
- **可信度**：⭐⭐⭐⭐⭐（全球性峰会论坛）
- **受众**：主流媒体高层、城市宣传主管领导

## 四、社区 / 社群（前5个）

### 1. 中国记协新媒体专业委员会
- **类型**：行业专业委员会
- **简介**：中国记协下属的专业委员会，汇聚全国主流媒体新媒体负责人。定期举办新媒体培训、研讨会、案例评选（如中国新媒体大会优秀案例征集）。
- **加入方式**：单位申请加入
- **来源URL**：http://www.zgjx.cn
- **可信度**：⭐⭐⭐⭐⭐（官方组织）
- **活跃度**：年度会议+不定期线上活动

### 2. 融媒体中心交流社群（微信）
- **类型**：微信社群（多个活跃群）
- **简介**：全国各地县级/市级融媒体中心从业者自发组织的交流群。日常讨论内容涵盖城市宣传选题、文旅传播策划、平台运营技巧、政务新媒体案例。
- **加入方式**：通过传媒类公众号文章底部扫码、同行邀请
- **来源URL**：关注「传媒茶话会」「广电独家」等推文中偶有入群入口
- **可信度**：⭐⭐⭐（行业自发组织）
- **活跃度**：高度活跃，日常数百条消息

### 3. 全媒体运营师社群
- **类型**：微信社群 / 知识星球
- **简介**：以全媒体运营师职业资格认证为纽带形成的社群，成员包括传统媒体转型人员、城市文旅新媒体运营者。内容偏实战，涵盖短视频运营、直播策划、数据分析。
- **加入方式**：通过培训课程或知识星球付费加入
- **来源URL**：搜索「全媒体运营师 社群」
- **可信度**：⭐⭐⭐（商业化运营）
- **活跃度**：较高，定期有案例分享

### 4. 中国报业协会融媒分会社群
- **类型**：行业协会社群
- **简介**：中国报业协会下设的融媒体分会，汇聚全国报业融媒从业者。组织线上分享、案例研讨、城市传播课题研究。
- **加入方式**：通过所在媒体单位申请加入
- **来源URL**：http://www.acep.org.cn （中国报业协会官网）
- **可信度**：⭐⭐⭐⭐（行业协会背景）
- **活跃度**：定期活动

### 5. 知识星球「城市传播与文旅新媒体」
- **类型**：知识星球付费社群
- **简介**：部分行业KOL开设的付费知识星球，内容为城市文旅新媒体案例拆解、运营方法论、资源对接。规模较小但内容聚焦。
- **加入方式**：知识星球App搜索相关关键词
- **来源URL**：知识星球App搜索
- **可信度**：⭐⭐⭐（KOL个人运营）
- **活跃度**：周更

## 五、行业协会 / 机构

### 1. 中华全国新闻工作者协会（中国记协）
- **简介**：中国新闻界全国性人民团体，主管全国新闻媒体从业者的行业自律与专业发展。下设新媒体专业委员会。
- **核心价值**：发布行业规范、组织新媒体大会、评选新闻奖、开展融媒体培训
- **来源URL**：http://www.zgjx.cn
- **可信度**：⭐⭐⭐⭐⭐

### 2. 中国报业协会
- **简介**：全国报纸行业的行业组织，主管单位为国家新闻出版署。下设融媒体分会。
- **核心价值**：发布报业融媒发展报告、组织报业融媒体交流会、城市报业传播力排行
- **来源URL**：http://www.acep.org.cn
- **可信度**：⭐⭐⭐⭐⭐

### 3. 中国广播电视社会组织联合会
- **简介**：全国广播电视行业的社会组织，原中国广播电视协会。下设城市台委员会。
- **核心价值**：城市广播电视媒体的融合转型指导、城市台新媒体案例交流、年度评优
- **来源URL**：http://www.crta.org.cn
- **可信度**：⭐⭐⭐⭐⭐

### 4. 中国互联网协会
- **简介**：互联网行业的全国性协会，下设媒体融合与传播工作委员会。
- **核心价值**：发布互联网+传媒报告、组织数字发展论坛、互联网赋能文旅传播研讨
- **来源URL**：http://www.isc.org.cn
- **可信度**：⭐⭐⭐⭐⭐

### 5. 文化和旅游部（产业发展司 / 资源开发司）
- **简介**：主管全国文旅产业发展的政府部门，发布文旅新媒体传播政策、文旅品牌推广计划。
- **核心价值**：文旅新媒体传播政策文件、城市文旅品牌评优（如国家级夜间文旅消费集聚区）、文旅传播数据报告
- **来源URL**：https://www.mct.gov.cn
- **可信度**：⭐⭐⭐⭐⭐

### 6. 各省级记协/报协/广电协会
- **简介**：各省对应的新闻工作者协会、报业协会、广播电视协会。组织区域性城市传播论坛和新媒体培训。
- **核心价值**：区域性的行业交流机会、地方城市宣传案例评选
- **来源URL**：搜索「XX省记协」或「XX省报业协会」
- **可信度**：⭐⭐⭐⭐⭐（官方）

## 七、调研说明

### 信源选取原则
1. **优先官方/半官方渠道**：传媒类头部公众号、国家级行业协会、政府主管部门
2. **排除标准**：已排除知乎、微信公众号个人文章（非官方媒体号）、百度百科
3. **可信度分级**：
   - ⭐⭐⭐⭐⭐：国家级官方机构/核心学术期刊
   - ⭐⭐⭐⭐：正规媒体/行业协会/专业研究机构
   - ⭐⭐⭐：行业自发组织/KOL内容

### 行业信息流建议
```
每日浏览：传媒茶话会 + 广电独家 + 城市进化论
每周追踪：德外5号 + 传媒内参 + 声动活泼/故事FM
每季关注：中国新媒体大会/网络媒体论坛动态
年度参考：中国记协/中国报业协会发布的行业报告
```

### 提示
- 以上信源均为公开可获取的行业信息渠道
- 微信公众号需在微信App内搜索关注
- 播客推荐优先使用「小宇宙」App订阅
- 行业会议的具体时间和议程需关注主办方官网的年度发布
