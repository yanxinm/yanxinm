## 一、行业心智模型（6个）

### 1. 「城市即媒介」模型
- **一句话**：城市不只是宣传的对象，城市本身就是一个巨大的媒介系统——每一条街道、每一栋建筑、每一个市民都在「传播」城市。
- **来源证据**：孙玮「作为媒介的城市」理论（Track 01），McLuhan「媒介即讯息」（Track 04），Kavaratzis「城市品牌化不是广告而是城市治理」（Track 04）
- **应用方式**：做城市宣传时，你的对手不是别的城市，而是城市本身的日常体验。如果城市体验不好（脏乱差、服务差），再好的宣传内容也是负资产。应先「把城市做好」，再「把城市讲好」。
- **局限**：传统媒体人容易过度依赖「内容生产」的杠杆，低估「线下体验」的权重。

### 2. 「政务×流量」张力模型
- **一句话**：传统新闻媒体的城市文旅宣传天然夹在「政务合规」与「流量逻辑」之间——太官方没人看，太野路子上级不批。
- **来源证据**：贺娇龙「官员网红」争议（Track 01），三审三校制度 vs 抖音实时发布（Track 03），政务新媒体考核四维体系（Track 06）
- **应用方式**：这条张力不是「选一边」，而是「在两端之间找到可接受的偏移量」。敏感内容偏政务端（合规优先），种草/攻略内容偏流量端（传播优先）。关键是在内容策划阶段就做好「合规预判」，而不是做完了再被毙。
- **局限**：不同城市/不同领导的「偏移容忍度」差异极大，此模型需要按当地情况调整。

### 3. 「城市IP生命周期」模型
- **一句话**：城市文旅IP有明确的生命周期——爆红→蜂拥→审美疲劳→沉淀/遗忘→重塑，每个阶段需要不同的传播策略。
- **来源证据**：淄博→哈尔滨→天水爆火路径（Track 01），「从网红到长红」行业共识（Track 06），平台算法对「过气热点」的降权机制（Track 06）
- **应用方式**：
  - 爆红期：快速承接流量，做好「承接内容矩阵」（攻略、服务信息）
  - 蜂拥期：差异化叙事（不止打卡，讲在地文化），避免同质化
  - 沉淀期：转向长期品牌建设（深度内容、用户UGC激励、口碑复利）
- **局限**：少数城市天生有强IP基础（成都/重庆），模型对「无IP城市」的适用性较弱。

### 4. 「跨平台×跨部门」协同模型
- **一句话**：城市文旅新媒体不是一个人/一个部门的活儿，是传统新闻采编 + 新媒体运营 + 文旅推广 + 政务部门的「四跨协同」。
- **来源证据**：融媒体中心运营模式（Track 03、05），「中央厨房」一次采集多平台分发（Track 06）、城市品牌活动6-10人团队配置（Track 03）
- **应用方式**：做城市文旅选题时，必须同时考虑「采编能产出什么素材」「文旅端有什么政策/kpi」「平台算法现在偏好什么」「政务端的审核红线」。缺任何一方都会导致项目卡住。
- **局限**：大城市的协同成本远低于小城市——小城市融媒体中心往往一个人干四个人的活，模型需要按团队规模降级。

### 5. 「种草→拔草→种草」闭环模型
- **一句话**：城市文旅新媒体的终极目标不是「内容做爆」，而是「内容→到访→分享→更多到访」的飞轮循环。
- **来源证据**：小红书种草逻辑（Track 02、06），DMO目的地营销理论（Track 04），房琪/itsRae等创作者「内容驱动旅行决策」模式（Track 01）
- **应用方式**：每篇城市文旅内容发布前自问三句话：
  1. 这条内容能让多少人产生「想去」的冲动？（种草力）
  2. 到访的人有没有被服务好？（体验力）
  3. 他们会不会自发分享？（裂变力）
- **局限**：此模型更适用于「旅游目的地型城市」，对「非旅游城市」的城市品牌宣传（如产业品牌、人才引进）需要调整。

### 6. 「AI加速×人脑把关」模型
- **一句话**：AIGC能大幅提升城市文旅内容的生产效率，但城市宣传的政治敏感性决定了「人必须在最后一关」。
- **来源证据**：AIGC工具在SOP各环节的效率提升60-90%（Track 03），城市宣传翻车案例（如2024年某地AI生成城市宣传片因历史事实错误被追责，Track 03）
- **应用方式**：AI可以做：初稿/初剪、素材关联、标题A/B测试、数据初盘。人必须做：事实核查、政治合规、调性把控、情感赋灵。
- **局限**：AI的能力边界在快速扩展，此模型需要每3-6个月重新评估。

## 二、标准 Playbook（8条决策启发式）

### PB1：选题「三看」法则
- 如果拿到一个城市文旅宣传任务，先看：**看日历**（节气/节日/节点）→ **看热点**（本地/全国热搜）→ **看政策**（文旅局当下主推方向）。三看都指向同一方向 → 大力投入；只指向一个方向 → 谨慎推进；三看都空 → 换题。
- 案例：五一「看日历」确定→「看热点」如果该城市在热搜→「看政策」如果文旅局在推→三看重合，可以做假期预热爆款。

### PB2：标题「三段式」公式
- 如果写城市文旅内容的标题/封面文案，用公式：**【城市名】+【情绪词/行动号召】+【具体利益点】**
- 案例：「南京 ｜ 春天一定要做的5件小事（本地人私藏路线）」 →
- 要素：城市名（定位准确）、情绪词/行动号召（「一定要」制造紧迫感）、具体利益点（「本地人私藏」信任背书）
- 反例：「南京市文旅局发布春季旅游倡议」——太官方，无利益点。

### PB3：平台「主次分明」法则
- 如果运营多平台矩阵，按平台特性分配内容精力：**抖音/视频号（50%）做短视频爆款 → 小红书（25%）种草攻略 → 微信公众号（15%）深度内容/政策解读 → 微博（10%）话题运营/实时互动**
- 比例按团队能力调整，但顺序不乱。抖音（娱乐流量）和小红书（种草流量）是城市文旅出圈主阵地，微信是沉淀阵地，微博是互动阵地。

### PB4：城市IP「不追风口，等风来」法则
- 如果城市没有「淄博式」出圈基础，不要强行制造爆款。把精力放在**系统化内容矩阵建设**上（攻略库、素材库、城市故事库），等热点自然来临时有足够「弹药」。
- 案例：哈尔滨冰雪爆红之前有多年系统性的冰雪文化内容积累。强行制造爆款反而显得用力过猛。

### PB5：舆情「黄金4小时」法则
- 如果城市文旅内容出现负面舆情，**4小时内必须出回应**——1小时内研判定级，2小时内起草口径，4小时内发布首轮回应。
- 这里说的不是「危机公关」的黄金48小时，而是新媒体时代的「城市形象修复」时间窗口。首轮回应以「表态→安抚→承诺调查」为底线，不能沉默。

### PB6：三审三校「分级简化」法则
- 如果三审三校流程拖得太慢拖累时效性，**按内容风险分级**：红色内容（政策/敏感话题/领导人形象）→ 完整三审三校；黄色内容（景区推荐/美食攻略）→ 简化为一审一校；绿色内容（常规天气/节假日问候）→ 资深编辑可直接签发。

### PB7：AI辅助「5-80-15」法则
- 如果使用AIGC辅助内容生产，时间分配为：**AI初稿/初剪 50% → 人工修改+润色 30% → 人工终审 20%**。如果AI耗时超过50%说明工具选型有问题；如果人工终审时间少于20%说明审核不充分。

### PB8：城市故事「小切口·大共鸣」法则
- 如果做城市品牌传播类内容，**不要从「城市整体品牌」切入，从一个具体的人/故事/细节切入**。一个人→一座城→一种生活方式。
- 案例：「淄博烧烤」的故事起点不是「淄博烧烤很好吃」，而是「大学生到淄博吃烧烤被感动」——一个具体故事撬动整座城市的品牌。

## 三、工具栈与选型决策树

### 必备工具矩阵

| 层级 | 工具 | 用途 | 替代选项 |
|------|------|------|---------|
| 排版图文 | 135编辑器 / 秀米 | 公众号排版 | 可互相替代，建议同时装 |
| 视频剪辑 | 剪映专业版 | 90%+日常短视频 | 无需替代 |
| 数据分析 | 新榜 | 全平台基准数据 | 飞瓜/千瓜做深度 |
| 设计 | 稿定设计 / Canva | 海报/封面 | 创客贴 |
| 协同 | 飞书/石墨 | 选题会/排期 | WPS政务版 |
| 舆情 | 清博舆情 | 政务舆情标配 | 人民网/蚁坊 |
| AI辅助 | 文心一言/Kimi/豆包 | 文案初稿/灵感 | 各自互补 |

### 选型决策树

**融媒平台选型**（预算敏感型决策）：
- 省/副省级 → 索贝/大洋（全流程）或新华社MAGIC（AI优先）
- 地市级 → 封面新闻技术输出 / 人民网舆情融媒方案（性价比）
- 县级 → 轻量CMS即可，避免重资产

**舆情监测选型**：
- 省级/重点城市 → 人民网舆情（权威渠道直达决策层）
- 地市级 → 清博舆情（性价比最优）
- 随时预算低的 → 识微/蚁坊（SaaS轻部署）

### 避坑清单
1. 「大而全」融媒平台陷阱：买了一套几十万的CMS，结果只用到了排版+发布功能
2. AI迷信症：AI生成的初稿不经核查直接发布，导致事实错误
3. 舆情工具过度采购：小城市买了省级配置的舆情系统，70%功能用不上
4. 数据分析工具重叠：同时买新榜+飞瓜+千瓜+清博，数据打架
5. 视频工具选型错误：短视频用PR而不是剪映——学习成本高，效率反而不如免费工具

## 四、工作流 / Pipeline

### 入门SOP（10步）

```
01 需求对齐（30min）→ 02 素材搜集（1-2h）→ 03 选题策划（1h）→ 
04 脚本撰写（2-3h）→ 05 视觉制作（2-4h）→ 06 三审三校（1-2h）→ 
07 多平台适配（1h）→ 08 发布监测（30min）→ 09 数据复盘（1h）→ 
10 归档沉淀（30min）
总耗时：10-15小时（不含拍摄）
```

### 资深路径
- 总耗时压缩至**2-4小时**
- 可简化：需求对齐口头完成、素材直觉化调用、AI辅助脚本/初剪、模板化视觉生产
- 不可省略：敏感词/政策合规、评论区舆情监控首2h、多平台格式适配

### 三大场景工作流

| 场景 | 周期 | 核心步骤数 | 关键检查点 |
|------|------|-----------|-----------|
| 城市文旅短视频 | 2-3周 | 12步 | 政策扫描→热点研判→集体审片→评论区运营 |
| 城市品牌活动融媒体传播 | 3-6周 | 12步 | 资源摸底→舆情基线→执行排期→效果评估 |
| 舆情应对与城市形象修复 | 黄金24h+7-30天 | 6步 | 研判定级→口径起草→首轮回应→修复期运营 |

### 近期工作流变化
- AIGC将素材搜集速度提升80%，脚本撰写速度提升50%
- 抖音本地生活权重提升 → 城市文旅内容需要绑定POI
- 视频号社交分发增强 → 「朋友点赞」成为文旅内容新流量入口
- 三审三校增强版（2025年后） → AI辅助审核初步引入，但终审责任仍由人承担

## 五、行业表达 DNA

### 高频用语 / 黑话
- 外行说：「做城市宣传」—— 行内说：「打造城市IP」「城市种草」「目的地营销（DMO）」
- 外行说：「发一篇推文」—— 行内说：「做一条内容」「矩阵分发」「多端联动」
- 外行说：「让更多人知道这座城市」—— 行内说：「提升城市品牌声量」「扩大传播触达」「破圈」
- 外行说：「看看效果怎么样」—— 行内说：「复盘一下」「看数据」「完播率/CTR/互动率如何」

### 严肃讨论 vs 轻松吐槽
- 正式场合（汇报/对外）：「我们在强化城市品牌的内容叙事」「以在地文化赋能文旅融合」
- 内部吐槽（编辑部/开会）：「这稿子太官腔了，没人看」「领导又要做那个没人看的专题了」「又碰到敏感词了，得改」

### 内外沟通差异
- 对外说：「我们拥有一流的传播策划和执行能力」
- 对内说：「这次能不能爆全靠首发3秒的完播率，封面图换3版了」

### 外行常见破绽
- 把城市宣传写成「通稿/工作总结」—— 应写成「可传播的内容（种草/故事/攻略）」
- 只用一种形式做所有平台的内容—— 应「一个核心内容，多平台适配」
- 忽略评论区运营—— 城市文旅内容的评论区是「二次内容生产」的重要阵地
- 只谈城市优点不谈「温度」—— 成功的城市文旅内容要会「自黑」「接地气」

## 六、质量基准 + 反模式

### 什么算「好」

| 基准 | 优秀标准 | 验证方式 |
|------|---------|---------|
| 完播率（视频） | 第3秒 > 30%，完整 > 15% | 平台后台 |
| 互动率（种草） | > 5%（小红书），> 3%（抖音） | 新榜/平台后台 |
| 粉丝增长 | 月均增长 > 10%（新品）或 > 3%（成熟号） | 新榜 |
| 长尾传播 | 发布7天后仍有新增阅读/播放 > 初始期的20% | 平台后台 |
| 舆情健康度 | 负面评论占比 < 5%，无需要启动舆情响应的危机 | 清博/人工监测 |
| 「种草→到访」转化 | 内容关联POI的访问量/团购核销率 > 行业均值 | 本地生活后台 |

### 反模式（外行/新人常犯的10条错误）

1. **用通稿体做城市宣传**：「南京市文旅局深入贯彻落实……」→ 用户翻开3秒就关
2. **一稿多投不改编**：同样的内容和标题直接发到所有平台 → 各平台算法和用户群体完全不同
3. **忽略3秒完播率**：短视频前3秒放logo+标题 → 用户已经在3秒前滑走了
4. **评论区「洁癖」**：删掉所有负面评论 → 反而引发更多「被控评」的负面讨论（城市文旅内容的评论区是「二次内容生产场」）
5. **过度美化城市**：用精修图/滤镜失真 → 游客到现场发现差距太大 → 口碑反噬
6. **跟风追热点但没人设**：所有城市热点都蹭，但没有自己的内容IP → 账号标签混乱
7. **数据只看阅读量不看转化**：阅读量10万+但没有人到访 → 这是「自嗨」
8. **把新媒体当「报纸电子版」**：报纸内容直接贴到公众号 → 不同媒介需要不同的叙事方式
9. **忽略本地生活/POI绑定**：城市文旅内容没有挂POI/团购链接 → 流失潜在流量入口
10. **一个人干四个人的活还不出声**：小团队配置想做出大团队效果，但不向上申请资源 → 团队 burnout

## 七、智识谱系

### 主要流派

| 流派 | 奠基人 | 当前代表 | 核心主张 | 与城市文旅新媒体的关联 |
|------|--------|---------|---------|---------------------|
| 国际城市品牌学派 | Kotler (1993) | Anholt / Kavaratzis / Govers | 城市需像品牌一样系统化营销和管理 | 提供理论根基——城市宣传不是写稿，是品牌管理 |
| 中国城市传播学派 | 孙玮 (2010s) | 孙玮 / 复旦大学团队 | 城市本身就是媒介，传播发生在城市日常中 | 提供方法论——城市传播不是「通过媒体传」，是「让城市本身发声」 |
| 中国媒体融合学派 | 喻国明 (2014-) | 喻国明 / 各高校研究团队 | 传统媒体必须与新媒体进行组织/流程/内容的深度融合 | 提供组织框架——融媒体中心是城市宣传的新基础设施 |
| 中国城市营销定量学派 | 刘彦平 (2010-) | 社科院团队 | 用指标体系量化城市品牌竞争力 | 提供评估标尺——让城市品牌「可量化、可追踪」 |
| 政务新媒体实战派 | 各地文旅局长 (2020-) | 贺娇龙 / 刘洪 / 哈尔滨文旅团队 | 官员站台+短视频出圈是最快的城市引流方式 | 提供可复制案例——从0到1的城市文旅IP打造路径 |
| 文旅内容创作者派 | 房琪等 (2018-) | 房琪kiki / itsRae / 星球研究所 | 用内容创作者而非官方口吻讲述城市，将文旅做成「内容产品」 | 提供表达范式——轻松、个人化、有审美，才是新媒体的城市语言 |

### 核心分歧（矛盾保留）

1. **学术派 vs 实战派**：孙玮等学者认为城市传播是「解构式」的学术问题，贺娇龙等实战派认为就是「把内容做爆」——两者各有道理，前者提供理论深度，后者提供实操方案
2. **中央媒体 vs 地方媒体**：人民日报/新华社等央媒的转型路径（资源密集、品牌沉淀深厚）无法直接复制到地市/县级媒体（预算少、人才缺、品牌弱）
3. **政务合规 vs 内容自由**：同一内容，政务审核要求「严谨、不出错」，新媒体运营要求「有爆点、敢表达」——两种要求本身存在不可消除的张力
4. **国际理论 vs 中国语境**：Kotler城市营销理论在西方的「市场竞争」逻辑，在中国需要嵌套「政府主导+舆论调控」的现实框架

## 八、诚实边界

1. **信息时效**：调研时间为2026年5月，平台算法、工具价格、监管政策为高频变量，工具/工作流模块衰减最快。建议每3个月复查工具和平台规则变化。
2. **部分来源无法在线验证**：由于调研当日web_search工具对中文查询间歇性不可用，部分调研内容（尤其是中文语境的具体案例和价格信息）基于行业知识整理，未能在当日完成线上复核。
3. **城市差异性**：本Skill的「通用OS」基于行业共性提炼，但不同行政级别（省/地市/县）、不同地域（东部/西部）、不同领导风格下，具体操作路径可能有显著差异。
4. **不替代城市线下体验**：城市品牌传播的底层逻辑是「城市本身做得好→传播放大」，如果城市文旅服务/基础设施建设存在短板，再好的传播内容也会被线下体验反噬。
5. **公开信息来源偏差**：成功城市案例（淄博、哈尔滨等）曝光远多于失败案例，存在「幸存者偏差」——不意味着按照同样的路径就能复制同样的成功。
6. **不替代行业实操经验**：本Skill提供的是行业认知操作系统，不是「自动爆款生成器」——城市文旅宣传需要结合当地具体情况进行创造性应用。

## 九、Agentic Protocol（7个研究维度）

当Skill拿到一个城市文旅宣传新问题时，应按以下7个维度做功课再输出判断：

### 维度1：城市画像与品牌现状
- **核心问题**：这座城市目前的核心IP是什么？品牌声量在什么水平？
- **搜索动作**：查刘彦平「城市品牌影响力指数」排名、百度指数城市热度趋势、携程/美团数据（游客量/消费额）

### 维度2：政策与节点扫描
- **核心问题**：当下文旅局主推什么？有没有政策红利/节庆节点？
- **搜索动作**：搜该城市文旅局官网/公众号最近1个月推文、文旅部最新政策文件、节气/节假日日历

### 维度3：竞品/对标分析
- **核心问题**：同级别/同区域的其他城市最近做了什么内容？效果如何？
- **搜索动作**：搜新榜/飞瓜上同类城市文旅账号的数据、最近出圈的城市案例拆解

### 维度4：平台算法与趋势研判
- **核心问题**：目标平台（抖音/小红书/微信视频号）当前的流量偏好是什么？有无算法变化？
- **搜索动作**：搜平台官方创作者大会信息、行业分析(德外5号/传媒茶话会)、近期城市文旅爆款的内容特征拆解

### 维度5：资源与能力评估
- **核心问题**：团队规模/预算/技术能力能支撑什么级别的执行？
- **搜索动作**：无外部搜索——此维度基于用户自身描述。需要用户提供：团队人数、预算范围、已有内容矩阵情况

### 维度6：舆情与风险扫描
- **核心问题**：该城市/该主题有没有历史舆情风险？什么话题容易触红？
- **搜索动作**：搜清博/人民网舆情对该城市近期舆情报告、敏感词库检查、该城市文旅相关的历史负面事件

### 维度7：效果评估与复盘框架
- **核心问题**：做完之后怎么算「做好了」？
- **搜索动作**：预设KPI指标（完播率/互动率/粉丝增长/到访转化）、复盘模板、行业基准数据
