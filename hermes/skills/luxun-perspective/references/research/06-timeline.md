# 鲁迅生平完整时间线（1881–1936）

> Agent 6 输出 | 梳理鲁迅生平的完整时间线和关键节点

---

## 一、少年时期：家道中落与离家求学（1881–1898）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1881年9月25日** | 出生于浙江绍兴东昌坊口新台门周家 | 原名周樟寿，字豫才，后改名周树人 |
| **1886年（约5岁）** | 入私塾，从远房叔祖周玉田读《鉴略》 | 开始接受传统启蒙教育 |
| **1892年（约11岁）** | 转入绍兴城内最严厉的私塾——**三味书屋**，师从寿镜吾先生 | 打下扎实的古文功底；后作《从百草园到三味书屋》回忆此段 |
| **1893年（12岁）** | 祖父周介孚因科场舞弊案下狱（"周福清案"） | 家道急转直下，为避祸寄居亲戚家，尝尽世态炎凉 |
| **1896年（15岁）** | 父亲周伯宜病逝（长期酗酒、吐血） | 作为长子，频繁出入当铺和药铺；这段经历深刻影响其日后对中医的态度（见《父亲的病》） |
| **1898年5月（17岁）** | **离开绍兴，赴南京求学** | 带着母亲筹措的8元路费，考入**江南水师学堂**（管轮班） |

> **阶段特征**：从"破落户的少爷"沦为"穷亲戚"，目睹封建家族制度的虚伪与残酷，埋下对旧礼教反抗的种子。

## 二、南京求学时期（1898–1901）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1898年** | 考入江南水师学堂（南京），接触"新学" | 报章、格致、算学、地理等西学课程让他眼界大开 |
| **1899年** | 转入**江南陆师学堂附设的矿务铁路学堂** | 学习采矿、地质、铁路等；首次读到严复译《天演论》（赫胥黎），"物竞天择"思想震撼其世界观 |
| **1901年** | 以优异成绩从矿路学堂毕业 | 毕业文凭记载其总评为一等 |

> **思想萌芽**：接触进化论，"将来必胜于过去，青年必胜于老人"成为其早期核心信念之一。萌生"科学救国"的志向。

---

## 三、日本留学时期（1902–1909）⭐ 核心转折

### 3.1 弘文学院阶段（1902–1904）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1902年3月** | 以官费生身份赴日留学，入读东京**弘文学院**（速成普通科） | 学习日语和基础科学 |
| **1903年** | 剪掉辫子，拍摄"断发照"；广泛阅读西方哲学、文学 | 翻译儒勒·凡尔纳《月界旅行》等科学小说；作《自题小像》"寄意寒星荃不察，我以我血荐轩辕" |
| **1904年** | 从弘文学院毕业 | 决定学医，以"救治像我父亲似的被误的病人的疾苦" |

### 3.2 仙台医专时期（1904–1906）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1904年9月** | 入读**仙台医学专门学校**（今东北大学医学部） | 唯一的外国留学生，受到解剖学教师**藤野严九郎**的特别关照（后作《藤野先生》） |
| **1906年初（约1月）** | **"幻灯片事件"**——在课间观看日俄战争幻灯片，见中国人替俄国做间谍被日军处决，周围中国同学却麻木围观叫好 | 思想受到巨大冲击 |
| **1906年3月** | **弃医从文**——退学离开仙台，返回东京 | 认识到"凡是愚弱的国民……第一要著，是在改变他们的精神" |

### 3.3 东京文艺运动时期（1906–1909）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1906年夏** | 奉母命回国与朱安结婚，婚后数日即返日 | 封建包办婚姻成为其终生精神负担 |
| **1907年** | 与弟周作人一起筹办文艺杂志《新生》，后因资金匮乏流产 | 首次尝试文艺救国 |
| **1908年** | 师从章太炎学习《说文解字》，受其反清革命思想影响 | 加入光复会 |
| **1908–1909年** | 大量译介外国文学：编译《域外小说集》（与周作人合译） | 介绍东欧、北欧被压迫民族文学（显克微支、安特莱夫等） |
| **1909年8月** | 因经济困难，结束留日生涯，返回中国 | |

> **关键思想转折**：⚡ **1906年——弃医从文**。从"科学救国"转向"文艺救国"，这是鲁迅一生最重要的思想转变。进化论（科学）＋ 被压迫民族文学（文艺）＋ 章太炎（革命）三线交汇，奠定其思想底色。

## 四、回国沉默期：抄碑、教育与蛰伏（1909–1918）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1909年9月** | 回国，在浙江杭州**浙江两级师范学堂**任教（生理、化学） | 开始步入教育界 |
| **1910年** | 回绍兴，任绍兴府中学堂教务长兼博物教员 | |
| **1911年10月** | 辛亥革命爆发，绍兴光复，组织"越社"欢迎革命军 | 对革命抱有期望 |
| **1912年初** | 应教育总长蔡元培之邀，赴南京任教育部部员 | |
| **1912年5月** | **随教育部迁往北京**，任社会教育司第二科科长 | 住绍兴会馆（**补树书屋**） |
| **1912–1918年** | **抄古碑、辑录金石、校勘古籍** | 大量辑录《嵇康集》、搜集汉画像石拓片等，在巨大的苦闷中埋头故纸堆 |
| **1913年** | 创作文言小说《怀旧》，发表于《小说月报》 | 唯一一篇文言小说 |
| **1917年** | 张勋复辟，愤而辞职（后复职） | 对政治现实极度失望 |
| **1917–1918年** | 钱玄同（《新青年》编辑）多次来访，劝其为《新青年》撰稿 | 著名的"铁屋子"对话——"然而几个人既然起来，你不能说决没有毁坏这铁屋的希望" |

> **阶段特征**：表面上的"沉默期"（1909–1918，近十年），实为思想积累与精神准备期。辛亥革命后的失望、袁世凯称帝、张勋复辟等事件让他陷入深度幻灭，抄古碑既是自我麻醉，也是文化梳理。钱玄同的邀约成为引爆点。

> **思想状态**：⚡ **深刻孤独与幻灭**——"这寂寞又一天一天的长大起来，如大毒蛇，缠住了我的灵魂了"（《〈呐喊〉自序》）。

## 五、呐喊时期：新文化运动与小说创作高潮（1918–1926）

| 时间 | 事件 | 核心作品 | 备注 |
|------|------|----------|------|
| **1918年4月** | 创作第一篇白话短篇小说 | **《狂人日记》** | 中国现代文学史上第一篇白话小说，发表于《新青年》第4卷第5号 |
| **1918年5月** | **正式以"鲁迅"为笔名发表《狂人日记》** | | 笔名首次使用；"礼教吃人"成为时代最强音 |
| **1918–1919年** | 在《新青年》陆续发表《孔乙己》《药》等小说 | **《孔乙己》《药》** | 塑造了封建社会底层知识分子的经典形象 |
| **1919年5月** | 五四运动爆发 | | 鲁迅并非运动组织者，但其文学创作极大地鼓舞了运动 |
| **1919年8月** | 发表《我之节烈观》，猛烈抨击封建贞操观 | | 第一篇重要杂文 |
| **1919年11月** | 买下北京八道湾11号住宅，12月接母亲及朱安来京 | | 与周作人一家同住 |
| **1920年** | 开始在北京大学、北京高师等校兼课 | | 讲授中国小说史 |
| **1921年12月** | 连载 | **《阿Q正传》** | 分章发表于《晨报副刊》；阿Q成为世界文学中"精神胜利法"的经典形象 |
| **1923年8月** | 出版第一部小说集 | **《呐喊》**（收入1918–1922年小说14篇） | 中国现代文学的奠基之作 |
| **1923年7月** | 与周作人兄弟**决裂** | | 搬出八道湾，迁居砖塔胡同61号 |
| **1924年2月** | 创作《祝福》《在酒楼上》《肥皂》等 | **《祝福》**（祥林嫂） | 收入第二部小说集 |
| **1924–1925年** | 任教北京女子高等师范学校，与学生**许广平**相识并通信 | | 师生恋开端，后成为终身伴侣 |
| **1924年11月** | 支持创办《语丝》周刊，成为主要撰稿人 | | 形成以鲁迅为核心的"语丝派" |
| **1924–1926年** | 创作散文诗集 | **《野草》**（1927年出版，收23篇） | 中国现代散文诗的巅峰；"当我沉默着的时候，我觉得充实；我将开口，同时感到空虚" |
| **1925年** | 支持女师大学潮，公开批判教育总长章士钊 | | 后免去教育部佥事职务（1925年8月），次年胜诉复职 |
| **1925–1926年** | 创作回忆性散文10篇 | **《朝花夕拾》**（1928年出版） | 从童年回忆中汲取力量 |
| **1926年8月** | 出版第二部小说集 | **《彷徨》**（收入11篇小说） | "路漫漫其修远兮，吾将上下而求索" |
| **1926年8月26日** | **离开北京，南下赴厦门** | | 因被段祺瑞政府通缉名单列入，加上与许广平约定分别工作两年 |

> **阶段特征**：⚡ **1918年——第一次"呐喊"**。从沉默中爆发，以白话小说掀起中国文学革命。《呐喊》是理想主义的喷发期；《彷徨》则是战斗中的犹疑与自我拷问。10年间创作了中国现代文学最经典的作品群。

> **思想状态**：从进化论的乐观到面对现实"深沉的韧性的战斗"；对人性的阴暗面有了更深的认识。

## 六、厦门大学与中山大学时期（1926.8–1927.9）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1926年9月** | 抵厦门，任**厦门大学**国文系教授兼国学院研究教授 | 编写《中国文学史》讲义（未完稿） |
| **1926年9月–1927年1月** | 在厦大期间完成《朝花夕拾》最后5篇；与许广平通信集《两地书》 | 厦门相对安宁的环境给了他短暂的创作期 |
| **1927年1月** | 离开厦门大学，前往广州，任**中山大学**文学系主任兼教务主任 | 与许广平在广州汇合 |
| **1927年3月** | 与许广平在广州同居 | |
| **1927年4月12日** | 蒋介石发动**四一二反革命政变** | |
| **1927年4月15日** | 广州发生"四一五清党"，国民党大规模逮捕和屠杀共产党人及左派学生 | 鲁迅营救被捕学生无效 |
| **1927年4月21日** | **愤而辞去中山大学一切职务** | 对国民党彻底绝望 |
| **1927年9月27日** | 与许广平离开广州，同赴上海 | 结束教育生涯，开启最后的人生阶段 |

> **关键思想转折**：⚡ **1927年——清党冲击**。亲眼目睹"血的游戏"，革命青年惨遭屠杀，对进化论的信念彻底动摇。鲁迅自己说："我一向是相信进化论的……后来我明白我倒是错了。" 这标志着他从进化论转向阶级论，思想更加激进。

## 七、上海时期（最后十年）：杂文时代（1927–1936）⭐ 最辉煌的创作期

### 7.1 定居上海（1927–1929）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1927年10月** | 定居上海，住在虹口景云里23号 | 选择租界为据点，以避国民党迫害 |
| **1927年12月** | 任《语丝》主编；主编《未名丛刊》 | 开始以自由撰稿人和编辑为生 |
| **1928年** | 与创造社、太阳社展开"革命文学论战" | 被左翼青年围攻为"封建余孽""二重反革命"；鲁迅开始系统研读马克思主义文艺理论 |
| **1929年9月** | 儿子**周海婴**出生 | 晚年得子，给鲁迅带来极大的情感慰藉 |

### 7.2 左联时期（1930–1936）

| 时间 | 事件 | 核心作品 | 备注 |
|------|------|----------|------|
| **1930年2月** | 发起成立"中国自由运动大同盟" | | 与柔石等人共同发起 |
| **1930年3月2日** | **中国左翼作家联盟（左联）成立**，鲁迅为发起人之一和实际精神领袖 | | 在成立大会上作著名演讲《对于左翼作家联盟的意见》 |
| **1930年5月** | 被国民党浙江省党部呈请"通缉"，避居花园庄旅馆 | | 此后多次进出避难 |
| **1931年1月** | 柔石等左联五烈士被国民党秘密杀害 | | 鲁迅被迫携全家避居日本人开的公寓；悲痛中作《为了忘却的记念》 |
| **1931–1933年** | 大量写作杂文，主编或参与编辑《萌芽》《前哨》《十字街头》等 | **《二心集》**（1932） | 标志鲁迅杂文进入成熟期 |
| **1932年11月** | 回北京探望病危的母亲 | | 在北京各大学作"北平五讲" |
| **1933年1月** | 加入蔡元培、宋庆龄发起的**中国民权保障同盟** | | 任执行委员 |
| **1933年4月** | 迁居大陆新村9号（现鲁迅故居） | | 在上海最后的住所 |
| **1933年6月** | 民权保障同盟总干事杨铨（杨杏佛）被暗杀 | | 鲁迅送殓时出门不带钥匙，以示不惧暗杀 |
| **1933–1934年** | 以几十个笔名在《申报·自由谈》等报刊发表大量杂文 | **《南腔北调集》**（1934）**《伪自由书》**（1933）**《准风月谈》**（1934） | 杂文创作的巅峰期；"匕首与投枪"式战斗 |
| **1934年** | 创作最后一篇小说**《非攻》**（收入《故事新编》） | **《故事新编》**（1936年出版，收入8篇"神话、传说及史实的演义"） | 晚年转向历史题材的寓言式写作 |
| **1935年** | 翻译果戈理《死魂灵》完成；写作《理水》《采薇》《起死》等 | **《死魂灵》**译本 | 以翻译为生命最后阶段的重大工程 |

> **阶段特征**：⚡ **左联时期**——从小说家转型为"杂文家"。10年间写下约700篇杂文，结集为《三闲集》《二心集》《南腔北调集》《伪自由书》《准风月谈》《花边文学》《且介亭杂文》等。鲁迅自评："我的杂文，所写的常是一鼻，一嘴，一毛，但合起来，已几乎是或一形象的全体。"

> **思想状态**：认同马克思主义文艺理论，但保持独立批判立场，与党内教条主义者（"四条汉子"等）时有冲突。对国民党的文化围剿进行寸步不让的斗争。

## 八、逝世前12个月：最后的战斗（1935.10–1936.10）

| 时间 | 事件 | 核心活动 | 备注 |
|------|------|----------|------|
| **1935年秋** | 肺结核病情加重，开始频繁咳嗽、发热 | 仍坚持写作和翻译 | 长期吸烟（日抽50支以上）严重损伤健康 |
| **1935年11月** | 翻译俄国作家果戈理《死魂灵》第一部完成 | 翻译 | 在重病中完成，被认为是其翻译生涯的代表作 |
| **1935年12月** | 写作历史小说**《采薇》** | 创作 | 《故事新编》收官之作 |
| **1936年1月** | 肺病再次发作，肋膜积水 | 抱病编定《故事新编》 | 最后一部小说集 |
| **1936年3月** | 病情加重，体重骤降；史沫特莱（美国记者）请来上海最好的肺病专家托马斯·邓恩诊断 | 美国医生诊断后称"恐怕已经来不及了" | 鲁迅拒绝去苏联疗养的建议 |
| **1936年4月** | 冯雪峰从陕北瓦窑堡到上海，住鲁迅家，传达中共抗日民族统一战线政策 | 政治联络 | 鲁迅表示拥护党的政策，但不参加组织 |
| **1936年5月** | 病情急剧恶化，至5月底已不能起床 | | 宋庆龄写信恳请住院治疗 |
| **1936年6月** | **病中答《救亡日报》记者问**，提出"**民族革命战争的大众文学**"口号 | 政治/文学活动 | 与"国防文学"口号论争，坚持左翼文学立场 |
| **1936年6月** | 写作**《答托洛茨基派的信》** | 政治表态 | 公开抨击托派，拥护中共抗日统一战线；信中坦言："那切切实实，足踏在地上，为着现在中国人的生存而流血奋斗者，我得引为同志，是自以为光荣的。" |
| **1936年8月** | 写作**《答徐懋庸并关于抗日统一战线问题》** | 文学论争/政治声明 | 著名的长文，系统阐述对文艺界统一战线的主张 |
| **1936年8–9月** | 身体稍有好转，仍坚持写作和编校 | 编订《且介亭杂文》末编、《苏联版画集》作序 | 生命最后时刻仍在工作 |
| **1936年9月5日** | 写作散文**《死》**（遗嘱体） | 遗言 | "……欧洲人临死时，往往有一种仪式，是请别人宽恕，自己也宽恕了别人……我的怨敌可谓多矣……让他们怨恨去，我一个也不宽恕" |
| **1936年9月20日** | 写作**《这也是生活》** | 随笔 | "无穷的远方，无数的人们，都和我有关" |
| **1936年10月初** | 最后的公开露面：参观**第二回全国木刻流动展览会** | 文化活动 | 与青年木刻家座谈，留下最后的照片 |
| **1936年10月17日** | 病势突然转剧，气喘不止 | | 连夜请日本医生须藤五百三诊治 |
| **1936年10月18日** | 凌晨病情危急，天明后由冯雪峰等送往医院 | | 已无法言语 |
| **1936年10月19日凌晨5时25分** | **在上海大陆新村9号寓所逝世**，享年55岁 | | 临终前仍手执香烟，遗容安详 |

> **逝世后事**：
> - 10月22日，上海各界举行送葬，数万人自发上街送行
> - 灵柩上覆盖"民族魂"白布旗，由宋庆龄、蔡元培、沈钧儒等扶棺
> - 葬于上海万国公墓（后迁至虹口鲁迅公园）
> - 毛泽东评价："鲁迅的方向，就是中华民族新文化的方向"

## 九、关键思想转折点总览

| 序号 | 时间 | 转折点 | 核心变化 |
|------|------|--------|----------|
| **T1** | **1906年** | **弃医从文** | 科学救国 → 文艺救国（首要的是改造国民精神） |
| **T2** | **1918年** | **发表《狂人日记》** | 十年沉默 → 彻底爆发；文言 → 白话；个人 → 公共知识分子 |
| **T3** | **1927年** | **清党（广州"四一五"）** | 进化论 → 阶级论（"我"的进化论轰毁）；教育救国 → 直面政治 |
| **T4** | **1930年** | **加入左联** | 个体批判 → 有组织的集团战斗；开始系统运用马克思主义分析 |
| **T5** | **1936年** | **病逝** | 生命终结，但其批判精神与文学遗产成为中国现代精神的核心资源 |
