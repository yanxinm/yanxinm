# 飞书自建应用机器人加入群聊指南

## 问题

飞书自建应用（Custom App）机器人不会出现在群聊「添加机器人」的默认列表中。用户只能看到「自定义机器人」（webhook 模式），而找不到 Hermes Agent 机器人。

## 原因

飞书商店上架的公开机器人会自动出现在搜索列表里。自建应用机器人需要手动在**飞书开放平台后台**开启「可被搜索并添加至群聊」开关，否则用户无法通过群聊的「添加机器人」功能找到它。

## 操作步骤

### 1. 开启群聊搜索权限

1. 打开 **[飞书开放平台](https://open.feishu.cn)**，扫码登录
2. 在「我的应用」中找到 Hermes Agent 对应的应用
   - 当前 App ID: `cli_a96f0509c8f89cee`
   - 可以直接访问：`https://open.feishu.cn/app/<APP_ID>`
3. 左侧菜单 → **「应用功能」→「机器人」**
4. 找到 **「群聊设置」** 区域
5. 开启以下开关（具体名称以后台为准）：
   - ✅ **机器人可被搜索并添加至群聊**
   - ✅ 相关群聊权限（发送消息、接收群消息等）
6. 点击右上角 **「发布」**（走发布流程，新版本上线后才生效）

### 2. 拉进群

等发布生效后：

1. 打开目标群聊 → 右上角群设置 → **群机器人 → 添加机器人**
2. 在搜索框中输入应用名称（如 "Hermes Agent" 或应用的中文名）
3. 搜到后点击添加 → 确认

### 3. 配置要求（Gateway 侧）

`.env` 中需要设置以下参数（已有）：

```ini
FEISHU_ALLOW_ALL_USERS=true       # 允许所有用户私聊
FEISHU_GROUP_POLICY=open          # 允许加入群聊
FEISHU_DOMAIN=feishu              # 域名（feishu 或 larksuite）
FEISHU_CONNECTION_MODE=websocket  # 连接模式
```

> **注意：** `FEISHU_GROUP_POLICY=open` 只是 Gateway 侧允入群聊，是否能在群聊搜索中找到机器人，取决于飞书开放平台侧的配置。

## 常见坑

- 修改开放平台的机器人配置后，必须**发布新版本**才会生效，不是保存就立即有效的
- 如果是国际版飞书（Lark），`FEISHU_DOMAIN` 需要设为 `larksuite`，开放平台入口也不同
- 机器人加入群聊后需要被 @ 才会回复（取决于 Gateway 配置，默认行为）
