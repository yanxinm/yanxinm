# 旅行行程海报生成工作流

## 两种方案对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **文生图（gpt-image-2）** | 视觉设计感强，色彩丰富 | 中文文字可能出错，需逐字验证 | 行程信息图，用户偏好视觉感 |
| **代码排版（PIL）** | 文字100%准确 | 太简陋会被嫌弃"太丑" | 需要精确文字的场景 |

## ⚠️ 文生图关键规则

1. **必须用中文写 prompt** — 英文 prompt 会导致中文变英文
2. 调用 Hermes Web UI 端点（不是直连 apikey.fun，避免 401）
3. 每次生成后必须 `vision_analyze` 逐字验证中文准确性
4. 重点检查：酒店名、美食名、问候语、日期字号
5. 问候语不能写成拼音
6. 生成尺寸可能异常（如 941×1672 而非 1024×1440），需注意
7. 中文 prompt 中 emoji 会被渲染为图标，是好事
8. 输出路径统一用 `/home/miao/出图/DayN_地点_终稿.jpg`

## 终稿排版规则（2026-06-20 贵州自驾项目确认）

1. **日期**放最上面，字号最小，浅灰色
2. **问候语**第二排，字号最大，彩色（绿+蓝），带绿叶图标
3. **Day N** 字号小，在问候语下方
4. **时间线**按实际发生顺序排列，用竖线+圆点串联，每个节点左侧时间右侧图标+文字
5. **天气+穿搭**永远放最后，底部双栏卡片
6. **底部装饰**用 subtle line art

## 色彩要求
- **明亮活泼**，不要素雅冷淡
- 彩色时间标签（红橙绿蓝紫粉色块）
- 鲜艳图标（emoji 或彩色小图标）
- 每个行程节点都有对应图标

## 代码排版精致化要求

简单卡片版会被嫌弃"太丑"。必须用：
- 时间轴 + 彩色标签 + emoji + 底部双栏卡片的精致布局
- 配色：暖米白背景 #FAF6F0，深绿标题 #4A6B5A，珊瑚橙点缀 #D4846A
- 左侧时间标签：绿色圆角矩形，白色文字
- 时间线：绿色竖线 + 珊瑚橙圆点

## 用户偏好
- 用户偏好文生图的视觉设计感
- 文生图文字出错 → 修正 prompt 重试，不要直接改用代码排版
- 如果代码排版被要求，必须精致化，不能太简陋
