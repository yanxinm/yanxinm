# 旅行行程规划

## 适用场景
用户说"帮我规划行程"、"出几份行程建议"、"做一份旅行攻略"、"定制路线"时，按此流程执行。

## 用户偏好（已确认）
- **狗肉不出现在美食推荐中**
- **住宿偏好**：
  - 优先新酒店（开业三年内），可适当考虑优质民宿（苗寨除外不住）
  - 交通便利+自有停车场
  - 苗寨/古镇看夜景后住附近城市酒店（如苗寨→凯里40min）
  - 房间配置确认：数量、床型、床宽（如1大床+3双床≥1.35m）
- **行程表格**：喜欢逐日表格格式（时间 | 内容 | 备注），带 emoji 前缀
- **输出格式**：优先 HTML 单文件（手机友好，卡片式布局暖色系，max-width 600px，含 checkbox），备用 PDF。不用 PDF 发手机（乱码）。

## 输出格式规范

### 行程表格格式
```
| 时间 | 内容 | 备注 |
|:----:|:----|:------|
| 08:00 | 🥟 早餐 | 推荐XXX |
```

**emoji 前缀规则**：
- 🛬 航班/到达 | 🚗 自驾/交通 | 🏨 住宿
- 🥟 早餐 | 🍜 午餐/晚餐 | 🍢 小吃/夜市
- 🌊/🏞️ 自然景点 | 🏘️/🏰 人文景点
- 🌆/🌃 傍晚/夜景 | 🛌 休息
- ✈️ 回程

### 推荐结构
1. **封面/总览** — 日期、交通方式、行程路线一句话
2. **主体行程** — 逐日列出，每天一张表
3. **费用预估** — 分类表格 + 人均总花费
4. **行前 Checklist** — 需预约/携带事项
5. **美食地图** — 按城市列出推荐美食

## 工作流程

### Step 1: 确认基本信息
用户需求清单：
- 出发地/目的地/日期/天数
- 交通方式（自驾/高铁/飞机）
- 必去景点（用户指定的不可省略）
- 约束条件（单日车程/预算/节奏松紧）
- 同行人员（一家三口/朋友/独自）

### Step 2: 出多方案
通常出 **3个方案** 供用户选择：
- **方案一：经典全景线** — 大众首选，覆盖核心景点
- **方案二：深度体验线** — 节奏更慢，增加某类深度体验
- **方案三：轻松漫游线** — 最轻松，日均活动最少
各方案标注特色标签，让用户一眼看出区别。

### Step 3: 细化选定方案
用户选定后，逐日细化到具体时间点，包括：
- 车程时间（精确到0.5h）
- 餐饮推荐（具体菜品+店铺/区域）
- 门票价格
- 住宿推荐
- 预约提醒

### Step 4: 生成文档
- **✅ 优先 HTML**：单文件，手机直接打开，暖色卡片式布局（max-width 600px，#f5f0eb背景，白色card圆角12px阴影，#2d5016主色调）。参考 `references/html-itinerary-template.md`
- **❌ 不主动出 PDF**：用户反馈"手机打开是乱码"。Noto CJK 字体不含 emoji 字形，且手机 PDF 阅读器体验差。只在用户明确要求桌面打印版时才生成 PDF。

## 酒店预订（详见 references/hotel-booking-workflow.md）

⛔ **不要用 web_search 或 browser 搜索中国三四线城市的酒店。** 搜索引擎几乎只返回酒类广告、无关页面；携程/美团要求登录且防爬严格。酒店搜索通过 agent 工具是死路。

✅ 正确做法：输出结构化订房清单 → 用户在携程/美团 App 自行搜索 → 订好告知 → agent 同步行程。

## 贵州路线模式（已验证）

### 模式A：苗寨+黔北环线（经典）
```
贵阳 → 荔波(小七孔) → 千户苗寨 → 凯里 → 遵义 → 茅台 → 黄果树 → 贵阳
```
- 注意：Day3荔波→苗寨→凯里 车程超2.5h上限
- 小七孔Day7往返贵阳7h是最大痛点，优先推荐住荔波

### 模式B：弃苗寨+织金+赤水（中等强度）
```
贵阳 → 安顺(黄果树) → 织金洞 → 遵义 → 茅台 → 赤水丹霞 → 贵阳 → 小七孔 → 荔波 → 机场
```
- 黄果树西门进只走精华（陡坡塘→天星桥下半段→大瀑布，约5h）
- Day3 织金→遵义 和 Day6 赤水→贵阳 是长途日（3h+）

### 模式C：乌蒙草原版（最轻松，已实战验证）
```
贵阳机场 → 安顺 → 黄果树 → 织金 → 乌蒙大草原 → 遵义 → 茅台 → 赤水 → 贵阳
```
- 去掉小七孔/荔波，加入乌蒙大草原（六盘水），总驾驶~1350km，人均3100-5000元
- 最长单日3.5h（乌蒙→遵义），比小七孔往返7h轻松很多
- **⭐ 关键优化（实战验证）**：Day2黄果树出来后直接去织金住宿（不等Day3早上），Day3织金洞半天→下午到乌蒙入住。省一晚住宿，节奏更紧凑。
- **⭐ 赤水深度变体**：乌蒙只需半天→Day4下午赶遵义→赤水多住一晚→Day6全天从容玩大瀑布+佛光岩+四洞沟+燕子岩。优点：赤水从"赶路打卡"升级为"深度体验"。适用场景：用户嫌草原一整天太长。
- 乌蒙海拔2800m，带厚外套防晒防风；景区内住宿极少，六盘水市区40min备选
- 预约：黄果树7.19西门 / 织金洞7.20 / 遵义会址7.21（或Day4到遵义后7.21）

### 模式D：荔波→织金直穿
```
贵阳 → 荔波(小七孔) → 都匀(午餐虾酸牛肉) → 织金洞 → 黄果树 → 茅台 → 赤水丹霞 → 贵阳
```

## Pitfalls

| 问题 | 解决 |
|------|------|
| 景区不提前预约进不去 | 所有热门景区（黄果树、小七孔、遵义会址）必须提前1-3天预约 |
| 单日车程超标 | 自驾行程单日≤2.5h，超过需用户确认 |
| 苗寨/古镇住宿体验差 | 建议看夜景后住附近城市酒店（如苗寨→凯里40min） |
| 狗肉出现在美食推荐 | ❌ 永不推荐。花江狗肉等虽为贵州名菜但一律不写，替换为当地其他特色 |
| PDF 中文字体乱码 | 从 Windows Fonts 复制 simhei.ttf 和 msyh.ttc 到 /tmp 使用。基地 Noto CJK 字体可用但不含 emoji 字形 |
| 微信发送限流 | iLink 频繁发送会 rate limit。等待30-60秒重试，或改用飞书发送 |
| 🆕 贵州小城市酒店搜索无效 | Agent web_search 很难搜到茅台镇/黄果树/乌蒙草原等三四线城市的酒店推荐。**2026.06 实测验证**：DuckDuckGo (`ddgs` 未安装 + `lite.duckduckgo.com` 超时) 均失败。携程需登录且防爬。**不要浪费大量工具调用去搜**——给用户筛选条件清单，让他们用手机 App 搜更快 |
| 🆕 酒店订房优先级 | 按城市酒店稀缺度排序：茅台镇 > 黄果树 > 遵义 > 凯里 > 贵阳 |
| 🆕 小七孔Day7往返 vs 住荔波 | 贵阳↔小七孔往返7h极累。优先推荐Day7玩完住荔波，Day8早荔波→机场（3.5h，9:00出发可赶上14:50飞机）。只有用户坚持最后住贵阳时才用往返方案。 |
