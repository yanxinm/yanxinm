# 酒店预订工作流

## 核心原则

**Agent 不要替用户在中文 OTA 平台（携程、美团、去哪儿）搜索酒店。** 这些平台对 web_search 不友好（搜索词被 SEO 污染），对 browser 工具严格防爬（弹登录墙、验证码）。

## Agent 该做什么

1. 从行程中提取住宿需求：城市、日期、房间数量、床型、特殊要求
2. 输出结构化订房清单（表格），包含统一的筛选条件
3. 用户自行在 App 搜索 → 预订 → 告知结果
4. Agent 同步更新行程 PDF

## Agent 不该做什么

- ❌ 用 web_search 搜 "茅台镇 酒店 推荐"
- ❌ 用 browser 打开 ctrip.com/hotels 搜索
- ❌ 试图比较酒店价格——数据不可得
- ❌ 编造酒店信息

## 订房清单模板

```
| 晚次 | 日期 | 城市 | 🛏️ 大床 | 🛏️🛏️ 双床×N | 状态 |
|:---:|:----:|:----:|:---:|:---:|:---:|
| X | M/D | 城市 | ❌ | ❌ | 待订 |
```

附带统一筛选条件表：
```
| 条件 | 要求 |
|------|------|
| 🆕 开业 | 三年内 |
| 🏨 类型 | 酒店优先，精品民宿可考虑 |
| 🚗 停车 | 自有停车场 |
| 🛏️ 大床房 | N间 |
| 🛏️🛏️ 双床房 | N间，床宽≥Xm |
```

## 已知的失败模式（2025-06-03 验证）

| 平台 | 尝试方式 | 结果 |
|------|---------|------|
| web_search | "茅台镇 酒店 推荐" | 返回酒类广告，无酒店信息 |
| web_search | site:ctrip.com 茅台镇 | 无关页面 |
| browser | hotels.ctrip.com 茅台镇 | 弹登录墙 |
| browser | tripadvisor.cn 茅台镇 | 可加载但内容陈旧 |
| web_search | mafengwo/xiaohongshu | 被搜索引擎拦截 |

唯一有效渠道：用户在手机 App（携程/美团）手动搜索。
