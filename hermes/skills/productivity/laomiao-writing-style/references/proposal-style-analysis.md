# 策划方案 风格分析摘要

> 分析自工作台账 2026/策划方案 及 非遗处/ 目录下26份docx

## 标题结构

典型双行：
```
[品牌Slogan]    ← 如"智享银龄 品质生活"
[完整方案名称]  ← 如"2026南京银龄生活荟策划方案"
（讨论稿）      ← 居中可选
```

## 五段式框架

1. 背景/缘起：1-2段引文（政策依据+现状+目的），无标题
2. 目标/定位："活动定位与目标"，四字短语概括
3. 内容/板块设计：60-70%篇幅，核心
4. 执行/排期/保障：宣传推广+任务分工
5. 预算/费用：通常另见独立文件

## 标准章节模板

一、活动主题/品牌
二、活动时间
三、组织架构（指导/主办/承办）
四、活动规划（最大章节）
  （一）主板块 → （二）配套 → （三）主题展示
五、新闻策划与传播
六、合作体系与招商
七、板块分工

## 开篇句式

"为贯彻/落实……，[主办方]立足[定位]，特策划[活动名称]系列活动。"

## 语言特征

- 政策用语：贯彻、落实、推动、促进、融合
- 四字短语：品牌长效化、非遗主题化、消费场景化
- 并列结构：一站式、沉浸式、高规格
- 人称：无第一人称，用"拟""将""拟开展"
