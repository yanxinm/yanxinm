# 工作总结与经营分析 风格分析摘要

> 分析自工作台账 2019-2026年度 30+份核心总结文档

## 标准四段式

一、年度/季度经营情况概述
  → 开篇综述：营收数据 + 完成率 + 同比分析 + 整体评价
  → 句式："YYYY年，在……领导下，……实现……"

二、主要工作/重点业务
  → 按板块平行展开（活动/旅游/金融/新媒体）
  → 每个板块：营收数据 + 重点项目 + 亮点

三、存在的问题与不足
  → 宏观原因优先（经济下行/预算收缩/市场变化）
  → 再提内部原因（人员/能力/流程）
  → 写法："一是……二是……三是……"

四、下年/下季度工作计划
  → 目标 + 方向 + 重点突破
  → 语气：坚定、务实、有信心

## 数据呈现

- 70%嵌入正文（文字叙述为主）
- 20%固定模板表格（考核评分表/绩效分配表）
- 0%使用图表（无饼图/折线图）
- 金额单位：万元，保留2位小数
- 完成率：百分数，保留2位小数

## 典型用语

营收数据："全年完成营收XXXX万元，完成率XX.XX%"
同比变化："同比+XX%（同比-XX%）"
项目描述："全年共完成XX个项目，合同金额XX万元"
问题表述："受经济下行/财政预算收紧/市场变化影响……"
改进方向："下一步将重点在……方面加强/突破"
