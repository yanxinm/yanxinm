# 月度工作报告与意识形态报告 风格分析摘要

> 分析自工作台账 2026/月度工作报告及意识形态报告/ 目录下15份docx文档

## 标题规范

| 类型 | 格式 |
|------|------|
| 月度重点 | 紫金山事业部X月重点工作 |
| 季度报告 | 紫金山事业部YYYY年X季度工作报告及X季度工作计划 |
| 意识形态月度 | 紫金山事业部X月意识形态（网络意识形态）领域情况分析研判报告 |
| 意识形态季度 | 紫金山事业部YYYY年X季度意识形态工作责任制落实情况自查报告 |

## 三段式结构

1. 工作回顾（组织学习→阵地管理→审核把关→成效）
2. 问题与整改（无问题→写"无"；有问题→逐条对应）
3. 风险与应对（每个风险：现象+危害→应对措施）

## 固定用语

- 开头："现将X月意识形态领域情况及问题……做如下汇报"
- 工作回顾："与中心工作一同规划、一同部署、一同落实"
- 应对："严格执行三审三校制度……从源头杜绝风险隐患"
- 结尾："部门负责人签字并盖章"

## 高频词

内容(37) 风险(29) 加强(22) 落实(20) 审核(19) 新媒体(20)

## 字体要求

- 主标题：方正小标宋_GBK 22pt
- 一级标题：黑体16pt加粗
- 正文：仿宋_GB2312 16pt
- 行距：固定28磅
- 首行缩进：2字符
- 页边距：上2.54cm 下2.54cm 左3.17cm 右3.17cm
