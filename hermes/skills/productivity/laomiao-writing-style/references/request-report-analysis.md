# 请示与报告 公文格式分析摘要

> 分析自工作台账 2026/请示和报告/ 目录下15份docx

## 标准结构

```
标题：关于[主题]的请示         ← 最常用
主送：集团领导：               ← 或"尊敬的领导："

正文：
  第一部分（缘由）：为……，按照……，现就……请示如下：
  第二部分（事项）：具体请示内容（分条列举）
  第三部分（结语）：当否/妥否，请批示。

落款：紫金山事业部
      2026年X月X日
```

## 结语选择

| 结语 | 语气 | 适用 |
|------|------|------|
| 当否，请批示。 | 标准 | 常规 |
| 当否，请批示！ | 稍强 | 紧急/重要 |
| 当否，请领导批示！ | 尊敬 | 强调 |
| 妥否，请领导审示。 | 审慎 | 预算/资金类 |
| 当否，望领导审阅批准。 | 复合 | 需多部门协调 |

## 附件格式

```
附件：1. XXXX
       2. XXXX
```

## 常用词汇

- 缘由：为、鉴于、由于、根据、按照、经
- 依据：根据……规定、按照……部署、经……研究
- 请示：拟、拟全面开展、需、特申请、恳请
- 结束：专款专用、全程接受监督审计

## 注意事项

- 请示=请求批复 (一文一事) vs 报告=汇报工作 (可一文多事)
- 避免混用：标题写"报告"正文用请示结语
- 日期必须完整：X年X月X日
