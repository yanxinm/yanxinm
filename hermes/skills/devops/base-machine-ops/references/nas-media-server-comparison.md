# NAS 系统与媒体服务器方案对比

> 2026-06-21 调研整理，用于基地存储与媒体播放方案决策。

## 基地硬件现状

| 组件 | 规格 |
|------|------|
| CPU | Intel i5-6600T (4核/4线程, 35W低功耗) |
| 内存 | 16GB DDR4 |
| NVMe | 256GB Samsung (系统盘, 122GB可用) |
| HDD-1 | 1TB ST1000LM024 (笔记本盘) |
| HDD-2 | 1TB ST1000VM002 (台式机盘) |
| 核显 | HD530 (QuickSync 支持 H.264/H.265/VP9, 不支持 AV1) |

### QuickSync 转码能力

| 视频格式 | 硬解支持 | 转码能力 |
|----------|----------|----------|
| H.264 | ✅ 完整支持 | 1080P 多路流畅 |
| H.265/HEVC | ✅ 支持 | 1080P 流畅，4K 单路 OK |
| VP9 | ✅ 支持 | 1080P 流畅 |
| AV1 | ❌ 不支持 | 需软解 |

## NAS 系统对比

| 方案 | 类型 | 授权 | 核心特点 | 适合场景 | 缺点 |
|------|------|------|----------|----------|------|
| **TrueNAS Scale** | DIY系统 | 免费 | ZFS文件系统、企业级数据安全、KVM虚拟化、Docker | 追求数据安全、有Linux基础 | 内存要求高(建议≥16GB ECC)、硬盘需统一容量 |
| **Unraid** | DIY系统 | $59起(永久) | 硬盘可混用不同容量、阵列灵活、Docker/VM支持 | 硬盘型号杂、逐步扩容需求 | 收费、性能略弱于ZFS |
| **OpenMediaVault** | DIY系统 | 免费 | 轻量(基于Debian)、插件丰富、资源占用低 | 低配机器、入门玩家 | 界面一般、ZFS支持弱 |
| **飞牛fnOS** | DIY系统 | 免费(国产) | 中文友好、内置穿透、AI功能、Docker | 国内用户、新手入门 | 生态不如老牌、ARM支持差 |
| **CasaOS** | 轻量方案 | 免费 | 极简、Docker管理器、可在现有系统叠加 | 已有Linux系统、只想管理容器 | 功能简单、无RAID |
| **群晖DSM** | 成品NAS | 绑定硬件 | 生态最强、Photos/Sync等套件完善 | 不想折腾、预算充足 | 硬件贵(授权绑定SN)、黑群晖风险 |
| **威联通QTS** | 成品NAS | 绑定硬件 | 性价比高、功能丰富 | 预算有限、需成品 | 界面复杂、学习成本 |

### 基地适配度

| 方案 | 适配度 | 理由 |
|------|--------|------|
| **OpenMediaVault** | ⭐⭐⭐⭐⭐ | 可直接在现有Ubuntu上安装，不重装系统，资源占用低 |
| **CasaOS** | ⭐⭐⭐⭐⭐ | 一行命令安装，叠加在现有系统上，Docker管理方便 |
| **飞牛fnOS** | ⭐⭐⭐ | 需单独安装系统，但中文友好、内置穿透 |
| **TrueNAS Scale** | ⭐⭐⭐ | 需重装系统，ZFS对硬盘要求高（两块HDD型号不同） |
| **Unraid** | ⭐⭐⭐ | 需重装系统，但硬盘混用友好，收费 |

## 媒体服务器对比

| 项目 | **Jellyfin** | **Emby** | **Plex** |
|------|-------------|----------|----------|
| **授权** | 完全免费开源 | 免费+付费解锁高级功能 | 免费+付费解锁高级功能 |
| **电影海报墙** | ✅ 支持，效果不错 | ✅ 支持，效果精美 | ✅ 支持，效果最好 |
| **音乐海报墙** | ⚠️ 支持但弱，无歌词 | ✅ 支持好，有歌词 | ✅ 支持最好，有歌词 |
| **刮削器** | TMDB/IMDB等 | TMDB/IMDB等 | 自家数据库最强 |
| **硬件转码** | ✅ 免费，Intel核显友好 | ✅ 需付费订阅 | ✅ 需付费订阅 |
| **客户端** | 全平台Web+App | 全平台Web+App | 全平台原生App最全 |
| **外网访问** | 需自己配穿透/域名 | 需自己配 | 官方提供中继服务 |
| **中文支持** | ✅ 好 | ✅ 好 | ✅ 好 |

### 结论
- **电影海报墙**：三家都行，Plex > Emby > Jellyfin
- **音乐海报墙**：Plex > Emby >> Jellyfin（Jellyfin音乐确实弱）

## 推荐方案

基于基地现状（已有Ubuntu + i5-6600T + 核显）：

**方案一：不动系统，直接Docker**
```bash
# Jellyfin（电影+电视）
# Navidrome（音乐）
# 两个都是一行docker命令
```
- 穿透用 Tailscale（已装）或 Funnel
- 海报墙效果：Jellyfin电影够用，Navidrome音乐很棒

**方案二：换成 OpenMediaVault**
- 系统更轻量，自带Web管理
- Docker装Jellyfin + Navidrome

**方案三：飞牛fnOS**
- 中文界面，内置穿透（FN Connect）
- 应用商店一键装Jellyfin
- 但音乐还得 Navidrome
