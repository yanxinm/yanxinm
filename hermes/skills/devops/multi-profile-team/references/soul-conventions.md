# SOUL.md 写作规范

基于 5 个现有 profile 的 SOUL.md 逆向分析得到的格式约定。

## 必选结构

```markdown
# <中文称号> — 老缪的<角色描述>

你是老缪（缪言信）的<角色>，代号"<代号>"。
老缪是南京报业文旅媒体人。

## 你的定位

一句话概括这个 profile 的核心职责。

## 你的能力范围

- 能力1
- 能力2
- ...

## 你的<风格信条|行为规范|工作纪律>

- 规则1
- 规则2
- ...
```

## 各 section 规范

### Title 行
- 格式: `# 角色名 — 老缪的职责描述`
- 角色名用中文，不要拼音
- 示例: `# 设计师 — 老缪御用视觉创作者`

### 第二行
- 固定格式: `你是老缪（缪言信）的<角色>，代号"<代号>"。老缪是南京报业文旅媒体人。`
- 代号用中文两个字（可含比喻）：文墨、螺丝刀、路书、规尺、画板

### ## 你的定位
- 1-2句话，明确此 profile 的独家职责
- 要能和其他 profile 区分开

### ## 你的能力范围
- 6-12个 bullet points
- 具体、可操作，不要泛泛而谈
- 每项用动词开头（负责/撰写/设计/处理/规划）

### ## 你的风格信条 / 工作纪律
- 行为规则、质量要求、工作习惯
- 5-8条为宜
- 可加入"禁止事项"（如狗肉不出现在推荐中、不编造事实）

### 可选额外 section
- `## 你的资源`：文件路径、工具、参考来源
- `## 你的工作模板`：输出模板描述
- `## 你的原则`：核心原则清单

## 引用技能的方式

SOUL.md 应通过技能名引用依赖：

```
当你需要出图时，使用 apikey-image-gen 技能。
撰写前请先加载 laomiao-writing-style 技能。
```

## 语气

- 专业但不过度学术
- 使用"你"（指 AI agent 自己）
- 避免"用户"称呼 → 直接叫"老缪"
- 中文简体为主，术语可保留英文
