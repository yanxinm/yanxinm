# 智能家居平台集成详情

## 已安装 Integrations

### 小米 Miot Auto (`xiaomi_miot`)
- Repo: https://github.com/al-one/hass-xiaomi-miot
- 配置: UI 添加集成 → 搜 `Xiaomi Miot Auto` → 小米账号+密码
- 服务器: cn

### Dreame Vacuum (`dreame_vacuum`)
- Repo: https://github.com/Tasshack/dreame-vacuum (2K+ stars)
- 功能: 完整替代APP，含地图、分区清扫

### 美的 (`midea_ac_lan`)
- 版本: v0.3.22（master 不兼容 HA 2026.6.1）
- Repo: https://github.com/georgezhao2010/midea_ac_lan (33368 downloads, 1676 stars)
- ⚠️ 勿用 `meiju` (hasscc/meiju) — 不兼容 2026.6

### 海尔 (`haier`)
- Repo: https://github.com/banto6/haier

### 树新风 Treeow (`treeow_home`)
- Repo: https://github.com/hlhk2017/treeow-homeassistant
- 设备: 空气净化器(T2Pro)、加湿器、净水器

### 晶御 Home Connect
- HA 内置集成，无需额外安装
- 品牌: 博世、西门子、嘉格纳

## 已放弃
- 华为智能门锁 AGS-Q10 (HarmonyOS 5.0) — 私有封闭协议，替代: Aqara门窗传感器
