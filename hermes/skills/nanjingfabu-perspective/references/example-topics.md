# 南京发布技能研究与策划样例

> 生成日期：2026年5月14日

## 五个原创选题样例

### 选题一：梧桐树的"户籍员"
- 角度：南京市园林局为每棵梧桐建电子档案
- 核心钩子："每棵树都有身份证"
- 推荐排期：5-6月（梧桐飞絮季前后）
- 预期传播力：⭐⭐⭐⭐⭐

### 选题二：明城墙的"体检报告"
- 角度：城墙保护中心用激光扫描/传感器给城墙做"体检"
- 核心钩子："600岁城墙每年做CT"
- 推荐排期：6月（文化和自然遗产日）
- 预期传播力：⭐⭐⭐⭐

### 选题三：秦淮河的"清洁师"
- 角度：水面保洁队从河面上看南京
- 核心钩子："从河面上看南京"
- 推荐排期：7月（夏季亲水期）
- 预期传播力：⭐⭐⭐⭐⭐

### 选题四：老门东"第三条巷子"
- 角度：主街背后的原住民生活
- 核心钩子："一墙之隔，两个世界"
- 推荐排期：周末排期
- 预期传播力：⭐⭐⭐⭐

### 选题五：南京的"声音收藏家"
- 角度：一个人录了二十年的城市声音
- 核心钩子："听，这就是南京"
- 推荐排期：年末盘点季
- 预期传播力：⭐⭐⭐⭐⭐
