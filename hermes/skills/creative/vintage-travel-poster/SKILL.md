# 复古旅行海报技能

## 来源
学习自小红书「小小AI设计师」/「随心设计」系列5城复古旅行海报（北京、上海、南京、哈尔滨、重庆），涵盖1960s、1970s风格。

## 模板结构（三明治布局）

```
┌──────────────────────────────┐
│  纯色背景（城市代表色）      │  ← 约占25%
│  大字白色城市名              │
│  印章（左上角/右上角）       │
├──────────────────────────────┤
│  黑白/棕调手绘线稿城市插画   │  ← 约占45-50%
│  前景：传统文化地标           │
│  背景：现代天际线摩天楼       │
│  古今对比                     │
├──────────────────────────────┤
│  米色/浅卡其底               │  ← 约占25-30%
│  左：机场三字码+机场英文名    │
│  中：经纬度坐标+中国·城市名   │
│  右：旅行年代+POSTER印章      │
│  水印：小红书号               │
└──────────────────────────────┘
```

## 详细布局与参数

### 顶部（彩色背景区）
| 元素 | 参数 |
|------|------|
| 背景色 | 城市代表纯色（红/蓝/藏青/黄等） |
| 城市名 | 白色粗体大字，竖向居中偏上 |
| 副标题 | 城市名+"市"，带★分隔，字号约主标题1/3 |
| 右上圆章 | 直径≈70px，"中国·城市名"上方弧形，建筑图标居中，英文名下方 |
| 右下小方块 | "随心设计"字样 |
| 年代标注 | 哈尔滨1950s / 北京、上海1960s / 南京1970s / 重庆1970s |

### 中部（线稿插画区）
| 元素 | 参数 |
|------|------|
| 画风 | 精细手绘线稿，黑白或棕调，有铅笔/版画纹理 |
| 构图 | 前景传统文化建筑+穿梭人流/车辆，中景河流/桥梁，背景现代摩天楼天际线 |
| 标志性建筑 | 突出城市最独特地标 |
| 标注 | 可对地标加引线和中文名+英文名标注 |
| 风格 | 模仿1960-70年代旅行宣传画的印刷质感 |

### 底部（米色旅行信息区）
| 区域 | 内容 |
|------|------|
| 左下 | [机场三字码] 方框 + 飞机图标 + 机场景文全称 |
| 中下 | 经纬度坐标° ′N ° ′E + ★ + "中国·城市名 CITY, CHINA" |
| 右下 | 圆形印章："旅行年代 {DECADE}s TRAVEL POSTER" + 邮戳效果 |
| 水印 | 小红书水印+用户ID（可选） |

## 提示词模板（豆包 Seedream）

### 标准版提示词（南京Demo验证通过的格式）

```markdown
复古旅行海报设计，{年代}风格。

【顶部】
{背景色描述}纯色背景。居中大字白色书法体城市名"{城市名}"，下方小字"{城市名}+市"带★分隔。右上角有圆形印章"中国·城市名"，内有简化地标图标。背景色占画面约1/4。

【中部】
精细手绘黑白/棕调线稿插画，占画面约1/2。前景为城市传统地标建筑（{前景地标描述}），有行人、车辆穿梭。中景有河流/桥梁。背景是城市摩天楼现代天际线。插画有印刷纹理感，复古{年代}风格。

【底部】
米白色背景，占画面约1/4。左下角机场三字码方框"{机场码}"+飞机图标+"{机场英文全称}"。居中经纬度坐标"{坐标}"+★+"中国·城市名 CITY, CHINA"。右下角圆形印章"旅行年代 {年代}s TRAVEL POSTER"。

【整体】
复古印刷风格，色彩以{顶部色}、米白、棕/黑线稿为主，模仿老旅行宣传画的质感。
```

### 生成参数
```bash
bash ~/.hermes/scripts/ark-image-gen.sh "完整提示词" doubao-seedream-4-5-251128 2048x2048 1
```

## 使用流程

1. **加载此 skill** — 确认城市名和年代风格
2. **查实景** — 确认城市代表色、标志性地标、三字码、坐标、机场景文全称
3. **填模板** — 按标准版提示词填写【顶部】【中部】【底部】【整体】
4. **生成** — 用 `ark-image-gen.sh` + 2048x2048 出图
5. **验证** — 用 `vision_analyze` 检查三层布局是否正确、地标是否可识别
6. **如不满意** → 让用户发参考海报样图 → 对比分析 → 修正提示词

## 实战经验（南京Demo验证）

### 第一次出图成功率
南京复古海报（藏青色顶+秦淮河线稿+1970s底部信息）**第一次出图即通过**，说明提示词结构化格式（【顶部】【中部】【底部】【整体】）有效。

### 关键约束
- **年代**必须是具体十年（1950s/1960s/1970s），不要写"复古"这种模糊词
- **顶部背景色**必须用精确颜色名称（藏青/中国红/深蓝/暖黄），不要写"深色"
- **中部线稿颜色**写"黑白棕调"比只写"黑白"效果好（增加复古印刷感）
- **底部信息**：机场码必须用IATA三字码（NKG/PEK/SHA/HRB/CKG），坐标精确到分
- **印章文字**：圆形印章必须写完整"旅行年代 {年代}s TRAVEL POSTER"
