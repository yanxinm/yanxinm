# 写实人像生成工作流

## 问题定义

需要生成**特定人物**（如猪猪/孙允珠风格）在**指定场景**（如南京街头）的写实照片。

## 核心原则

**纯文生图永远做不到精准面部还原** — 无论提示词多详细，模型都在"猜"一张"符合描述"的脸。要实现特定人物的面部一致性，必须用图生图（img2img）。

## 推荐工作流：Seedream 图生图（保留面部 + 换背景）

### 流程

1. **用户提供参考照片** — 一张猪猪的清晰正面/半身照（多角度更好）
2. **base64 编码参考照片**
3. **Seedream img2img 调用** — 以原图为底，提示词只描述场景/背景变化

### Seedream 图生图 API 调用

```bash
# base64 编码参考照片
B64=$(base64 -w0 /path/to/reference.jpg)

# 调用 Seedream img2img
curl -s -X POST "https://ark.cn-beijing.volces.com/api/v3/images/generations" \
  -H "Authorization: Bearer $ARK_IMAGE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"doubao-seedream-4-5-251128\",
    \"prompt\": \"Keep the person's face and body exactly as in the reference photo. Change the background to a street in Nanjing, China. Photorealistic style.\",
    \"image\": \"data:image/jpeg;base64,$B64\",
    \"size\": \"1920x1920\",
    \"n\": 1,
    \"response_format\": \"url\"
  }"
```

### 提示词原则

- ❌ **不要**在提示词中重复描述面部特征（会让模型试图"重画"脸部）
- ✅ **只要**描述场景/背景/光线/氛围
- ✅ 加上 `"Keep the person's face and body exactly as in the reference photo"` 来约束模型保留脸部
- ❌ 不要使用真实人名（猪猪/孙允珠/Son Yoon-ju）— 可能在部分模型触发肖像保护

### 尺寸要求

- Seedream 最小像素 3,686,400（即 1920×1920 或更大）
- 推荐 1920×1920 或 2048×2048

## 抠图效应（关键发现 2026-05-21）

### 问题现象
Seedream img2img 使用**纯色/简单背景参考照片**（如白墙自拍）时，模型倾向于：
- 把人物主体抠出 → 贴到新场景上
- 人物边缘生硬、光线与背景不匹配
- 整体像 PS 拼贴而非自然摄影

### 根因
Seedream 的 img2img 在处理"背景差异过大"的图片时，更倾向于**硬替换**而非**场景重渲染**。当输入的参考照片背景与目标场景差异极大（白墙→南京街头），模型没有足够的上下文来理解"这是同一个人在另一个地方"，而是理解为"把这个人的头部贴到另一个地方"。

### 解决方案

#### 方案一：选择"兼容"的参考照片（推荐 ✅）
- 优先选**已经有环境背景**的照片，而非纯色背景自拍
- 车内照（车窗可见城市街景）→ 改成南京街景 → 自然融合
- 户外照 → 改具体的南京地标 → 场景变换小，融合度高
- 室内窗边照 → 窗外风景改成南京地标 → 远景替换

#### 方案二：改写提示词策略
❌ **不要**用这种句式（暗示抠图替换）：
```
把背景改成南京街头，保持人物不变
```

✅ **改用**这种句式（暗示场景整体改变）：
```
这辆车停在中国南京的繁华街道上，车窗外是南京特色的梧桐树和民国建筑，阳光透过车窗洒进车内，保持车内人物和内饰完全不变
```

关键区别：不是"把背景改成"，而是描述一个完整的场景（"车停在南京"），让模型理解这是一个整体场景转换。

#### 方案三：两阶段法
- 阶段1：白墙自拍 → Seedream img2img → 放入一个简单室外场景（如公园长椅）
- 阶段2：公园照 → Seedream img2img → 精细化为南京街头
- 两阶段之间的渐变减少每次变换的跨度，降低抠图感

### 成功案例（2026-05-21）

| 参考照片 | 背景类型 | 提示词策略 | 效果 |
|---------|---------|-----------|------|
| 白墙自拍 | 纯色简单 ❌ | "把背景改成南京街头" | 抠图感明显 ❌ |
| 车内自拍（车窗有城市背景） | 复杂兼容 ✅ | "车停在南京街头，窗外是梧桐树和民国建筑" | 融合自然 ✅ |
