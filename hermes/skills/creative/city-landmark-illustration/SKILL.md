# 城市地标建筑插画技能

## 来源
学习自小红书「小小AI设计师」9个城市（洛阳、西安、武汉、海口、云浮、苏州、长沙、佛山、深圳）的地标插画及AI提示词。经南京12地标实战5轮迭代验证（v1-v5）。

## 风格定义：国潮扁平矢量手绘

| 要素 | 特征 |
|------|------|
| 画风 | 国潮扁平矢量手绘，线条粗细统一，纯色平涂 |
| 光影 | 无写实光影、无立体阴影 |
| 配色 | **低饱和淡雅色系**（青灰、米白、浅赭、淡蓝等），避免鲜艳高饱和 |
| 背景 | 纯白色干净背景 |
| 点缀 | 仅少量极简卡通小树，不抢建筑主体 |
| 布局 | 地标横向一字排开，前后错落形成天际线 |
| 文字规避 | 严禁出现任何文字（汉字、字母） |

## ⚠️ 实战关键教训（Nanjing v1-v5验证）

### 1. 画幅：必须用16:9宽画幅
**天际线插画绝不能用正方形画幅（2048x2048）**。6个以上地标在正方形里一定会被压缩变形。
- ✅ 正确尺寸：`2560x1440` 或 `3072x1728`（16:9，恰好满足Seedream最低像素要求）
- ❌ 错误尺寸：`2048x2048` → 建筑被压扁，排不下

### 2. 不准用地标原名，改用手绘描述
模型会被地标名称中的字**严重误导**：
- ❌ "紫峰大厦" → 模型关联"紫"→ 出紫色建筑（真实是银灰色）
- ✅ "银灰色玻璃幕墙三角形尖塔摩天楼" → 正确出银灰色

**规则**：列出地标后，每个必须附上一句精确的外形+颜色描述（参照真实照片），不能依赖模型"知道"它长什么样。

### 3. 配色一定要"低饱和淡雅"
模型默认倾向于用**鲜艳高饱和色**（大红、亮蓝、翠绿），与国潮淡雅风格矛盾。
- ✅ 推荐色系：**青灰、米白、浅赭、淡蓝、月白**（中国传统淡雅色）
- ✅ 提示词中要写：**"低饱和淡雅色系"** + 具体颜色列表
- ❌ 避免："红绿黄蓝"这种笼统说法 → 模型会理解成高饱和

### 4. 文字规避可能失败
对于极知名的建筑（如总统府），模型可能**自作主张加文字**，即使写了"严禁文字"。
- 在提示词中**多次强调**：画面不可出现任何文字、标注、招牌、汉字、字母
- 如果仍出现文字，需要更加明确（如"门面上不可写任何字"）

### 5. 地标数量控制
- **≤7个**：单行最安全
- **8-12个**：必须用16:9宽画幅 + 山体/桥梁做背景/贯穿元素 + 建筑缩小
- **>12个**：不可行，建议分批或合并

### 6. 山体/桥梁处理
天际线插画中，山体（栖霞山、牛首山）和桥梁（长江大桥）可以作为**背景/贯穿元素**，不占用天际线主行位置。提示词中要明确：
- "左侧背景：绿色山体点缀红叶"
- "右侧背景：金色穹顶位于山顶"
- "底部贯穿画面：灰色双层钢结构桥"

## 提示词6维模板

### 通用模板

```
主题：{城市名}城市地标天际线插画。

布局：所有地标横向一字排开在同一水平线上，前后错落有高低层次，连成连贯天际线，建筑尺寸精巧紧凑，确保所有元素在一行内完整排列，不分多排。

元素：包含{地标1+外形描述、地标2+外形描述……}；参照真实建筑的颜色和外形，不带任何招牌文字。

风格：国潮扁平矢量手绘插画；线条粗细统一，纯色平涂配色（{低饱和色系描述}）；无写实光影、无立体阴影，整体风格高度统一简约。

背景：纯白色干净背景，仅搭配少量极简卡通小树点缀（不抢建筑主体视觉）。

规避项：画面严禁出现任何文字（汉字、字母）、多余装饰花纹、杂乱背景、多余杂物元素，要求画风干净整洁。门面上不可写任何字。
```

### 生成参数
```bash
bash ~/.hermes/scripts/ark-image-gen.sh "完整提示词" doubao-seedream-4-5-251128 2560x1440 1
```

## 用户校正工作流（当用户说"不对"时）

当用户对生成的插画不满意时，其典型行为模式是：**发参考图给你看**。这是本 session 实战验证的关键工作流：

1. **停** — 不要猜错在哪里，直接让用户发参考照片
2. **看** — 用 `vision_analyze` 分析参考图的颜色、形状、比例、细节
3. **比** — 逐项对比参考图和之前生成的版本，列出每个地标的差异
4. **改** — 根据对比结果修正每个地标的外形描述（颜色、形状、结构细节）
5. **跑** — 更新提示词，再次生成
6. **验** — 再次用 vision_analyze 逐一核对，输出核对表给用户

**每次迭代都要输出核对表**（参考南京实战格式），让用户一眼看清哪些对了、哪些还有问题。

**关键经验**：模型对地标的"已知"信息往往是错的（紫峰大厦≠紫色，江苏大剧院≠球形），必须以用户提供的参考照片为准重写描述。

## 使用方式
1. 加载此 skill
2. 确认城市名、地标列表（≤12个）、配色关键词
3. 查真实照片，为每个地标写一句精确的外形描述（不可用地标原名代替）
4. 按6维模板填充 → 用2560x1440生成
5. 如需配图海报，再加载 fridge-magnet-poster skill（先生成插画，再套冰箱贴流程做海报）
6. 如果用户不满意 → 启用"用户校正工作流"（见上方）
