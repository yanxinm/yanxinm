# 竖构图照片裁切策略（冰箱贴海报专用）

## 问题

冰箱贴海报下半区固定 720px 高度（1080×1440 画布的 50%）。用户发来的照片可能是**竖构图（如 1152×2048，9:16 比例）**，主体可能占据画面 42%-100%，远超 720px。

**裁切错误：**
- 从图片**中心**裁 → 只显示主体腰部到小腿
- 从图片**底部**裁 → 只显示主体腰部以下
- 从图片**顶部**裁 → 只显示天空+建筑，主体完全丢失

## 解决：头部定位裁切法

1. 用 `vision_analyze` 问精确问题：
   > "请精确给出两个小朋友在照片中的纵向位置范围：他们的头顶在画面的什么位置（百分比），脚底在什么位置（百分比）？"

2. 计算裁切起始 Y：
   ```python
   photo = Image.open(path).convert("RGB")
   pw, ph = photo.size
   # 先缩放到宽度 1080
   scale = 1080 / pw
   photo = photo.resize((1080, int(ph * scale)), Image.LANCZOS)
   _, new_h = photo.size
   
   # 主体头顶在原图的百分比位置（来自 vision_analyze）
   kid_top_pct = 0.42  # 例：头顶在 42%
   crop_y = int(new_h * kid_top_pct)
   
   # 如果 crop_y + 720 > new_h，回退到从底部裁
   if crop_y + 720 > new_h:
       crop_y = new_h - 720
   
   photo = photo.crop((0, crop_y, 1080, crop_y + 720))
   ```

3. 如果主体从头到脚超过 720px（例如 42%-100% 跨度 = 58% × 1920 = 1114px）：
   - **优先保留头部和上半身** — 面部最重要
   - 从头顶开始取 720px → 显示到头到膝盖/小腿
   - 在消息中提前告知用户：照片太竖，装不下全身，已保留面部+上半身

## 一般化公式

```
缩放宽到目标宽度后高度 = 原高 × (目标宽 / 原宽)
主体像素高度 = 缩放后高度 × (脚底% - 头顶%)
裁切窗口 = min(720, 主体像素高度)  # 尽可能多装
```

如果 `主体像素高度 > 720` → 从头顶开始裁 720px → 这是最佳方案。
