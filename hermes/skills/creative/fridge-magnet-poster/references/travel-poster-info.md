# 旅行行程海报生成指南

## 两种海报类型（先区分再动手）

| 类型 | 用户说... | 风格 | 推荐方案 |
|------|----------|------|---------|
| 冰箱贴打卡 | "做冰箱贴"、"旅行纪念照" | 徽章+照片 | 文生图 / img2img |
| 行程信息图 | "出海报"、"行程卡片" | 文字为主+小图标 | **代码排版（PIL）** |

## 行程信息图结构模板

```
┌────────────────────────────┐
│ 问候语（小字，浅灰）         │  ← 如"出发啦！贵阳见～"
│ Day N（中号，主题色）       │
│ 日期（小号，灰色）          │
│ ───────────────────────    │  ← 分割线
│ [卡片] ✈️ 南京→贵阳 14:50   │
│ [卡片] 🚗 机场取车 · 1.5h   │
│ [卡片] 🏨 XX酒店            │
│ [卡片] 🍜 美食              │
│ [卡片] ☁️ 天气              │
│ [卡片] 👕 穿搭              │
│ ───────────────────────    │
│ 📍 地点备注（极小，浅灰）    │
└────────────────────────────┘
```

## 流程

1. 确认行程数据（从PDF/HTML提取酒店、美食、天气等）
2. **先用代码排版（PIL）出一版** — 中文文字必须准确
3. 输出到 `/home/miao/出图/`
4. 用户确认风格后，如需视觉增强可叠加文生图元素（但文字部分必须代码排版）
5. 用户确认后批量出剩余天数

## 两种方案对比（2026-06-20 贵州自驾项目实测）

| 维度 | 方案1：gpt-image-2 文生图 | 方案2：PIL 代码排版 |
|------|--------------------------|---------------------|
| 中文文字准确性 | ❌ 不可靠（浠岸→西安，夺夺粉→多多粉，裹卷→锅卷） | ✅ 100%准确 |
| 视觉设计感 | ✅ 卡片配色柔和、排版自然 | ⚠️ 偏模板化，需调参 |
| 迭代速度 | 慢（每次 ~60s + 人工检查） | 快（即时出图） |
| 推荐策略 | 仅用于生成装饰元素（底部插画、图标） | **文字+卡片全部用代码排版** |

## 文生图辅助方案（如用户坚持）

当用户坚持用文生图出完整海报时：
1. 提示词中用**拼音+英文辅助标注**关键中文词（如"浠岸酒店 XIAN HOTEL"）
2. 生成后用 `vision_analyze` 逐字检查中文准确性
3. 发现错字立即修正提示词重试
4. **不要相信第一次生成的中文文字**
5. 问候语用中文而非拼音（gpt-image-2 容易把问候语写成拼音）

## 用户排版偏好（2026-06-20 贵州自驾项目确认）

| 元素 | 字号优先级 | 说明 |
|------|-----------|------|
| 日期（7.18） | **最大** | 用户明确要求日期字号比 Day N 大 |
| Day N | 中等 | 比日期小，绿色主题色 |
| 问候语 | **最小** | 放最顶部，浅色 |
| 时间线事件 | 中等 | 时间标签小，描述文字清晰 |
| 天气/穿搭 | 中等 | 放最后，独立区块 |
| 底部装饰文字 | 最小 | 地点备注，浅灰色 |

**布局顺序**：问候语 → 日期 → Day N → 时间线行程 → 天气穿搭 → 底部装饰

## Pitfalls

- ❌ 第一天不要放黄果树（黄果树是 Day 2）
- ❌ 日期不要太大（但要比 Day N 大）
- ❌ 必须有问候语
- ❌ 穿搭要考虑涉水景点（雨衣/凉拖/防滑鞋）
- ❌ 文生图中文文字必须逐字验证
- ❌ 问候语不要写成拼音
- ✅ 代码排版是行程信息图的首选方案
- ✅ 输出路径统一用 `/home/miao/出图/DayN_地点_终稿.jpg`
