## 二、代表作品

### 🔥 1. 《疫苗之王》（2018年7月）—— 成名作与巅峰之作

- **发表时间**：2018年7月
- **首发平台**：微信公众号"兽楼处"
- **核心内容**：揭露长春长生生物科技公司疫苗造假——百白破疫苗效价不合格、狂犬病疫苗造假、生产记录造假等系统性质量问题。
- **社会影响**：
  - 微信阅读量数千万，全网刷屏级传播
  - 直接推动国家药监局介入调查
  - 长春长生被罚款91亿元，公司破产
  - 推动《中华人民共和国疫苗管理法》于2019年6月通过（中国首部疫苗管理专项法律）
  - 被评价为"一篇改变中国疫苗史的文章"
- **写作特点**：以韩刚君、高俊芳等关键人物的发家史为线索，通过人物故事串联起疫苗行业的系统性溃败，叙事张弛有度。

## 三、核心理念与写作风格

### 3.1 核心新闻观

1. **"铁肩担道义，辣手著文章"**
   - 继承中国传统新闻人的理想主义精神
   - 视调查报道为监督权力、保护弱者的武器

2. **"每一篇文章都是一次冒险"**（兽爷自述精神）
   - 敢于触碰敏感话题和禁区
   - 在审查环境下寻找表达空间
   - 不回避系统性问题的根源

3. **故事驱动的事实核查**
   - 先有人物，后有议题；先有故事，后有结论
   - 注重多方信源交叉验证，调查扎实
   - 不依赖二手信息，追求一手材料

### 3.2 写作方法论

| 维度 | 特点 |
|------|------|
| **叙事风格** | 特稿式写作（literary journalism），融合调查报道与文学叙事 |
| **结构设计** | 以小人物/具体人物切入，逐步展开宏大系统图景 |
| **语言特色** | 平实、克制、有力，偶有冷峻幽默，避免煽情 |
| **节奏控制** | 信息密度与叙事节奏平衡，逐层递进引出高潮 |
| **信息呈现** | 大量使用具体数字、时间线、人物对话，增强可信度 |

### 3.3 反复论述的核心主题

1. **制度性溃败与系统性腐败**
   - 不只揭露个案，更追问"为什么这种事反复发生"
   - 关注监管失灵、权力寻租、利益输送等结构性问题

2. **底层与弱势群体的生存困境**
   - 以普通人的命运为叙事锚点
   - 关注被系统碾压的个体（受害者、举报人、小人物）

3. **医疗安全与公共卫生**
   - 疫苗安全、药品造假、医疗事故是长期关注方向
   - 视医疗安全为民生底线

4. **房地产行业的黑暗面**
   - 从"售楼处"起家，对地产行业有深厚积累
   - 揭露房企债务陷阱、政商勾连、消费者欺诈

5. **权力与资本的悖论**
   - 追问权力如何被资本捕获，或资本如何寄生权力
   - 始终站在独立、批判的立场

### 3.4 创造的概念与术语

| 术语 | 含义 |
|------|------|
| **"兽楼处"** | 谐音"售楼处"，一语双关——既指向房地产（早期定位），也暗示"猛兽踞楼观察"的独立批判姿态 |
| **"兽爷"** | 笔名——"兽"字暗示猛兽般的锐利、不屈与攻击性 |
| **"树洞"概念** | 兽楼处公众号曾充当"树洞"角色，接收读者倾诉，收集一手线索（来源：Pekingnology文章中受访者自述） |
| **"疫苗之王"** | 既是文章标题，也成为一个公共话语符号——标志着中国公民社会对疫苗安全的觉醒 |

## 四、社会影响与历史定位

1. **政策推动**：《疫苗之王》直接助推《疫苗管理法》立法，被公认为中国自媒体推动公共政策变革的标志性案例。

2. **行业标杆**：兽楼处被海外媒体（如China Media Project）视为中国独立自媒体写作的典范，证明了在体制外做深度调查报道的可能性。

3. **模式创新**：从传统媒体记者转型为独立自媒体人，兽爷的路径代表了中国调查报道从机构媒体向个人品牌迁移的趋势。

4. **认知塑造**：创造了"疫苗之王"等公共话语符号，深刻影响了公众对医疗安全、房地产泡沫等议题的认知。
